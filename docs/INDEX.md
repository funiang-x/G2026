## 与工程文件的边界（别搞混）

本目录放**产品级事实与方案**；工程内的单一真相源另有其人（`02_优化方案_硬件与软件.md` §0 有完整口径表）：

| 类别 | 真相源 |
|---|---|
| 硬件事实（引脚 / 时钟 / 外设） | `firmware/Core/Inc/board_config.h` |
| 应用参数（周期 / 阈值 / 开关） | `firmware/project_config.h` |
| 硬件选型 / 架构 / pinout | `hardware/01-requirements.md` · `02-architecture.md` · `03-components.md` · `04-pinout连接表.md` |
| 数值复算 | `tools/verify_dsp.py` → `report_dsp_verify.md`；`hardware/verify_afe_v2.py` → `verify_afe_v2_report.md` |

**冲突时**：产品文档描述现状，skill / 分册描述硬约束——以硬约束为准，并把冲突**报告出来**（协议 §3.4）。
**三态口径**（工作台铁律 1）：凡涉及"上板"的结论一律为 **未验证**——装置尚未制造。
