## §1 做的几件事

### 1.1 用**桥**建无框纯文字（绕过工具链限制）

`easyeda sch` **没有 text-modify 也没有 create-text**，`sch frame apply` **只能建虚线框**（`lineType:0` 被拒），
但 EDA 桥（`http://127.0.0.1:49620/execute`）能直接调官方 API `eda.sch_PrimitiveText.create(x,y,content,rot,color,font,size)`。

