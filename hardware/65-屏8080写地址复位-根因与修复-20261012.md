## §0 一句话

本屏（**ST7796S** · 模块 TK035F9629 · 转接板 TK035F5501）**每收到一次 `0x2C`(RAMWR)
就把写地址复位到当前窗口的起点**；而本工程为了"采样窗静默"把一次 flush 切成
`APP_LCD_CHUNK_PX = 1024` 像素的块、**每块都重发一次 `0x2C`**
⇒ 每次 flush 只有窗口最前面约 3 行被反复覆写，**其余行从未被写过**（保持上电随机 GRAM）
⇒ 现象就是**整屏彩色雪花 + 几条均匀横线上才有界面**。

## §1 现象（修复前）

- 上电整屏彩色雪花；界面（LVGL demo）只出现在**几条均匀分布的细横线**上；右下角 sysmon 能刷新；
- 自检 `[SELFTEST] LCD ok, RDDID=00 FF FF FF` —— **假通过**（真值应为 `00 77 96 00`，
  读通道 `TRC` 160 ns / `TRCS` 45 ns 不满足，见 `_work/.../序列对比与诊断.md` §9）；
- 该现象与"屏坏了 / 接线错 / FSMC 时序不足 / IM 档位错"**都能兼容**，必须逐项切开，见 §3。

## §2 根因判据实验（J-Link 活体做，**不烧录**）

```
窗口 = 8 列 × 2 行（CASET 0..7 / RASET 0..1）
① 0x2C，写 8 个值 0111..0118
② 0x2C，写 8 个值 0121..0128
③ 0x2E(RAMRD) 读回该窗口
```
读回：**`0121 0122 0123 0124 0125 0126 0127 0128` + `FFFF × 8`**

⇒ 第二批**覆盖**了第一批 ⇒ **二次 `0x2C` 把写地址复位到窗口起点**（不是"接着上次的指针写"）。
第一批的 `0111..0118` 已不存在。

脚本：`_work/lcd_flashscreen_20261012/gen_ramwr_restart.py`（生成 `.jlink`，可复跑）。

## §3 同一批取证里被排除的项

| 假设 | 判据 | 结果 |
|---|---|---|
| 连接/总线不通 | `0x2E` 写唯一值 `0x1234` 读回 | ✅ 往返成功 ⇒ 写+读+窗口+GRAM 全通 |
| 固件"连发写"丢失 | 读回**固件刷的那块 GRAM** | ✅ 一整行 15 像素连续 `F800` ⇒ 写确实落盘 |
| IM 档位错 | 手册 §8.1（p.59）接口选择表 | ✅ `IM[2:0]=010` = **8080 16-bit(DB[15:0])**，与实物一致 |
| FSMC 时序太紧 | J-Link 把 `BTR1` 由 `0FF00CF2` 改到 `000028FF`（AS=15/DS=40，WR 高 ≈104 ns） | ❌ 屏无变化 |
| FSMC 配错 | 读回 `BCR1/BTR1` | ✅ `00001091`（SRAM/16 位/WREN/**Mode A**/非扩展）与 `Core/Src/fsmc.c` 一致 |
| 屏不听命令 | 现场发 `0x28` DISPOFF、3 s 后 `0x29` DISPON | ✅ 屏确实灭/亮 ⇒ 控制器、供电、背光都活着 |
| 初始化序列不匹配 | 现场重发屏厂 `Lcd_Initialize()` 整串 | ⚠️ 部分改善（横线变整屏宽）但**不解决行覆盖** ⇒ 是隐患、不是本次根因 |

## §5 影响面与遗留

- **判据（以后改显示代码必须守）**：一次窗口（`0x2A/0x2B` 之后）**只能发一次 `0x2C`**；
  要分块续写只能用 `bsp_lcd_write_pixels_cont()`。
  ⚠️ LVGL 上游注释写的"重复发 `0x2C` 无害（控制器接着当前指针写）"**对本屏不成立**。
- 采样窗静默（`hardware/02 §6 O1`）机制**不受影响**：仍按 `APP_LCD_CHUNK_PX` 逐块抢闸。
- **遗留（与本次根因无关，各自有判据）**：
  1. 触摸 FT6336 `I2C2` 无应答（`J5.24/26/27` 走线 + 上拉/供电）；
  2. 自检报"模拟轨可疑"（帧均值 ≈792 mV，期望 2048±307）⇒ 查 `JP2`/VBIAS 分压；
  3. 读通道时序不足 ⇒ `RDDID` 假通过、`bsp_lcd_self_check()` 判据偏松；
  4. 物理项：30pin 两排中心距（`hardware/60` 双源记 5.199 mm vs 底板 J5 的 2.54）、
     背光恒流合规（规格 60 mA，现为恒压直驱）、45pin FPC 座重插确认。
