## 2. 电源树（概要级，阶段二细化）

```
5V 单路入 ─┬─ 核心板 5V（板载 LDO 自供 MCU）── 排针引出 3.3V 仅作参考，不负载
           ├─ [数字 5V] ─ AMS1117-3.3 ─ 底板 3.3V（LCD 数字 / FT6336 / I2C 上拉） ~0.15A
           ├─ [模拟 5V]（LC 自输入分割）─ OPA2197（2mA）+ REF3033（50µA → VREF+ 与 1.65V 分压）
           └─ LCD 背光（晶体管自 5V，不进 3.3V/模拟轨）
```
