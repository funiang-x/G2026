## §1 一屏结论

| 问题 | 判定 |
|---|---|
| 接线表/映射表本身（48 号报告的 47 脚核对、`04` 的 P1/P2↔MCU 映射、J5 逐脚表） | ✅ **仍然成立，没有错** |
| 「核心板在下、从下方往上插」这个装法，配**现在的** EVK1 封装 | ❌ **几何上不可能对上**：核心板被迫翻面 ⇒ 整个针脚场左右镜像 ⇒ P1 组插进 P2 焊盘、P2 插进 P1，且每组奇偶两排互换 |
| 照夹心硬装、直接上电 | 🔥 **电源对短路**：核心板 3V3 针(P1-38) 插进转接板 77 号孔(GND)、GND(P1-39)→80 号(+5V)、5V0(P1-40)→79 号(GND)、AGND(P1-37)→78 号(+3V3) |
| 根因 | 核心板排针是**背面出针**（公针、丝印面那侧）；转接板 EVK1 封装按**核心板正面朝上从上方插**（标准底板架构）做的——活体 PCB 已验证无镜像。两种姿态互为镜像，**旋转不能抵消镜像** |

**用户发现"排针引脚好像错了" = 真错，但错在"插装方向"这一层，不在接线表。**

镜像 ≠ 任何二维旋转 ⇒ **不存在"换个方向插"的救法**。夹心装法要成立，只能改转接板的焊盘图案（§4 方案 B）。

## §3 照夹心硬装的错位表（长边为轴翻面时）

映射规则（可复算）：核心 P1 奇数 2k−1 → 转接板焊盘 40+2k；P1 偶数 2k → 39+2k；
P2 奇数 2k−1 → 焊盘 2k；P2 偶数 2k → 2k−1。抽样（焊盘网名取活体 dump）：

| 核心板针（丝印名） | 落到转接板焊盘 | 该盘现网名 | 后果 |
|---|---|---|---|
| P1-38 `3V3` | 77 | **GND** | 🔥 3V3↔GND 短路 |
| P1-39 `GND` | 80 | **+5V** | 🔥 GND↔5V 短路 |
| P1-40 `5V0` | 79 | **GND** | 🔥 5V↔GND 短路 |
| P1-37 `AGND` | 78 | **+3V3** | AGND 接 3V3（模拟轨毁） |
| P1-4 `A01`(PA1=AFE_ADC_IN) | 43 | 空(NC) | ADC 输入悬空 |
| P2-27 `D07`(PD7=LCD_CS) | 28 | 空(NC) | 片选悬空 |

（若改以短边为轴翻面，则 P1 组留在原位但行序反排：P1-38(3V3) 会落到焊盘 4 = AFE_ADC_IN 上——同样废，不展开。）

## §4 解决方案

### 方案 B（✅ 已定稿执行 2026-10-05）：保留夹心，镜像 EVK1 封装 —— 原理图零改动

> 适合"屏在最上、核心板藏在下"是外壳硬需求的情况。**现在改成本≈0**（PCB 尚未布线）。

**【执行记录 2026-10-05，全部实测回验】**

| 步骤 | 做法 | 结果 |
|---|---|---|
| 镜像实现 | **不改封装库**——PCB 上把 EVK1 器件整体翻到底层（API `setState_Layer(BOTTOM)`） | 翻层自动产生**水平镜像**（x → 2·2915−x，实测逐盘比对）；80 焊盘**编号、网络全部保持**（`_review/evk1_pads_after_flip.json`） |
| 陈旧项修补 | pad40（5V0）原理图 10-04 起两根 5V0 都接 `+5V`，PCB 导入漏了它 | `setState_Net("+5V")` 补上，回读 ✓（现位于镜像后坐标 2020,−7285） |
| 待人工 | EDA 里 **Ctrl+S 保存**；投板前整板重导网表（PCB 其余部分仍是陈旧导入） | — |

**【装配定义（唯一正确插法，写进装配丝印）】**

- 转接板：EVK1 双排母装**底面**（开口朝下）；J5 留**顶面**（屏从上方插）。
- 核心板：**短边为轴前后翻**（元件面朝下、丝印面朝上），再**逆时针转 90°**——
  **1 脚端（丝印 `REF\|A02` / `C09\|D03` 那头）朝东（J5 侧）、Type-C 端朝西**，从下方插进双排母。
  （镜像配对已数值验证：适配器 H 镜像 ↔ 核心板短边翻 + 逆时针 90°，pin n ↔ pad n 一一对应；
  **长边为轴的翻法对不上这个镜像，不许用**。）
- 布局自由度：若 Type-C 朝向与外壳冲突，把 EVK1 整体在 PCB 上旋转任意角度再重排即可——
  镜像关系不变，装配口令按新的 pad1 角重写。
- 防呆（布局阶段落丝印）：pad1 角三角标记（现位于镜像后东南角）+ 底面丝印
  「核心板丝印面朝本板 · 1脚端朝 J5」+ 非对称安装孔；180° 反插 = P1↔P2 整组互换，同样全毁。
- 机构：核心板挂于转接板下方 ≈8.5mm（排母高）+ 元件面朝下再 +2~3mm，外壳底部留 ≥15mm；
  Type-C/SWD 都是板缘件，布局时留侧面服务口或开窗。

1. **封装库**：复制 `LCKFB-LSPI-SkyStar-STM32F407VGT6-PRO` → 全选焊盘 → **水平镜像（编号随焊盘走）** → 另存 `…_MIR`。
   （镜像后 pad n 的位置 = 核心板翻面后 pin n 落点，一一对应，无需重排任何网络。）
2. **PCB**：EVK1 换用 `…_MIR` → **重导网表**（焊盘编号没变，网络按号自动对上；**原理图一根线不动**）。
   ⚠️ 现 PCB 是陈旧导入（pad40 空 vs 原理图 10-04 已接两根 5V0），重导时顺手校一遍电源针（§6-③）。
3. **装配定义（写进丝印和装配图）**：核心板**左右翻（长边为轴）、丝印面朝上、正面朝下**，从转接板**下方**插入；
   转接板 **底面**装 2×20 排母×2（开口朝下），J5 仍在**顶面**（屏从上方插，不变）。
   注意：封装镜像轴必须与核心板翻轴**配对**——左右翻 ↔ 封装左右镜像；若机构上必须前后翻（短边为轴），封装改上下镜像。
4. **防呆**：两组排针相距 35.6mm、左右对称 ⇒ **180° 反插风险仍在**（P1↔P2 整组互换，同样全错）。
   丝印标「核心板丝印面朝本板」+ 1 脚三角 + 非对称安装孔/外壳柱定位。
5. **机构注意**：核心板挂在转接板下方 ≈8~9mm（排母高度），正面（USB-C、按键）朝下——外壳底部留 ≥15mm；
   Type-C/SWD 都是板缘弯角件，留在同一短边、从侧面可达；SWD 若被遮，在转接板对应位置开服务窗。

### 方案 A：把夹心倒过来（零改动、零风险）

转接板完全不动（封装、`42`/`43` 布局提案原样有效）：**核心板正面朝上、从上方**插进顶面排母
（这正是封装假设的唯一姿态）；屏幕模块仍从上方插 J5，与核心板并排。
代价：核心板露在转接板上方（+20mm 级），"核心板藏在下"的外壳构想放弃。

### 方案 D（应急/台面过渡）：80 芯 IDC 排线

核心板丝印朝上（针朝上）压 2×20 IDC，另一端**旋转 180°** 插到转接板顶面排针——
反插那次镜像恰好抵消翻面镜像，转接板不用改。
缺点：33Ω 本应贴驱动端（核心板侧），现在落在远端；16 位并口走 80 芯排线 SI 有风险。
**只建议样机验证期用，不建议进外壳。**

### §4.6 J5 手性判定（2026-10-05 补）：**现封装在"玻璃朝上"插装下是对的，不换件、不镜像、不必转**

用户问"换 J5 怎么样"。手性比对结论：

- **换 J5 修不了 EVK1 侧**——两者无共享网络，核心板镜像只能靠 §4 方案 A/B 解决。
- **J5 现封装手性恰好正确**：模块丝印侧（针朝上可读）排布（列对式、CS 端起算）与 J5 现封装
  （pad1 东北角、pad2 正南、pad3 西邻——活体 dump 实测）**互为镜像**；而模块装进夹心必须翻面
  （玻璃朝上、针朝下），翻面把镜像翻回来 ⇒ 手性一致、pin n ↔ pad n 一一对应。
  ⇒ B10 当年换 C58377 逐行式时顺手把这件事做对了。
- **换"件"没有意义**：任何别家 2×15 排母的编号都等价于"转 180° 或镜像封装"，不产生第三种自由度。
- **四个角的可达变换**（活体 pad1=东北角为基准）：0°=东北 · 180°=西南 · 水平镜像=西北 · 垂直镜像=东南。
  真需要 pad1 换角时按此表选；旋转不动编号与网络（零成本），镜像需重导网表。
- **仍欠两条实物确认**：
  1. **玻璃与排针异面**（本节手性结论的前提；09-29 照片只见转接板不见玻璃，强烈指向异面）。
     若实物是同面 ⇒ 夹心直插装不上（玻璃朝下），改方案：J5 换**弯角排母**让模块立装，或屏改飞线——
     换的是**类型**不是编号。
  2. **插装方向标记**：针朝上、丝印可读时在模块 CS 端板边画记号 → 翻面看记号落在 J5 哪头 →
     把「屏 CS 端朝 J5 哪侧」写进装配丝印 + pad1 角标记。插反 180° 的后果 = CS 落到 3V3、GND 落到 RS（毁板级），
     与 EVK1 侧防呆同级，必须落丝印。
  （原挂账①「奇数排靠外/靠里」被 2 的记号法吸收——记号端+翻轴定了，行列自然定；背光测试保留为台面杜邦接线的复核手段。）

### §4.7 变体（用户 2026-10-05 提案）：核心板插**顶面** + 屏幕模块插**底面**（镜像 J5）

**手性验证：成立，用户直觉正确。**

- 核心板从上方正常插（正面朝上）⇒ 标准架构，**EVK1 封装一个焊盘都不用动**，§3 的镜像问题整个消失。
- 屏幕模块从转接板**下方**插（针朝上、插进底面 J5 排母）：此时模块呈现的是它**丝印侧原排布**
  （不发生翻面——丝印就印在出针面），手性与 J5 现封装（CW，pad1 东北、pad2 正南、pad3 西邻）**恰好相反**
  ⇒ **J5 需要镜像封装一次**（编号随盘走）+ 重导网表，pin n ↔ pad n 即对上。**原理图零改动。**
  （与 §4.6 不矛盾：上插 = 翻面呈现、手性恰好抵消；下插 = 不翻面呈现、手性错开——两种装法恰好互补。）
- ⚠️ **物理后果必须先拿模块实物比划 10 秒**：模块下插时针朝上，玻璃朝向由模块构造决定——
  ① 玻璃在排针**对面**（09-29 照片指向这种）⇒ 玻璃朝**下**对着桌面，显示不可见；
  ② 玻璃与排针**同面** ⇒ 玻璃朝上但被转接板挡住，除非 J5 放板缘让玻璃悬出板外。
  **"屏在下"只有玻璃能露出来且朝向用户才成立**；若实测露不出来，回到 §4 方案 B
  （镜像 EVK1、屏在顶面）——两者工作量完全相同（都是镜像一个封装 + 重导网表 + 丝印标记），
  差别只在玻璃最后朝哪。
- 布局注意（选此变体时）：J5 在底面 ⇒ FSMC 18 根线过孔换层，仍守 `37` 的「33Ω 贴 EVK1 侧 3~5mm、
  总线 ≤40mm」；J5 的去耦 `C21/C22` 随迁到底面贴 J5；屏模块成为底面噪声源，与 AFE 分处正反两面，
  对 `22` 的隔离诉求反而有利。
- 防呆：与正装同款——模块 CS 端记号 + J5 pad1 角标记 + 装配丝印；插反 180° = CS 落 3V3（毁板级）。

### 插装前最小万用表核对表（8 针，5 分钟）
