S1J1 · SMA-KE 母座信号入口
信号在此的变化
被测信号由 BNC 电缆经 SMA↔BNC 转接件进入底板。这一级信号不发生任何变换——它只完成「电缆 → PCB」的物理转接。50Ω 同轴系统要求接口的特征阻抗连续，所以座子必须是 50Ω 同轴结构，不能换成排针/端子。
理论公式与计算过程
  • 入口点的信号＝信号源电动势 Es 经源内阻 Rs 后的分压（见 S2）。
  • 转接件引入的阻抗不连续量级：ΔZ 引起的反射系数 Γ = (Z2−Z1)/(Z2+Z1)。SMA↔BNC 转接件的标称 ΔZ 很小，Γ 通常 < 0.05（≈ −26 dB），在 500 kHz 以下可忽略。
选型依据
题面说明 7 要求板上焊 BNC 座；用户已有 SMA-KE + BNC 转接件，电气上仍是 50Ω 同轴接口，机械上 SMA 座更小、可贴板边。外壳 4 脚全部接 AGND，给同轴信号电流提供屏蔽层回流路径，兼把外壳静电导入地。
⚠ PCB 硬约束：R1 必须贴 J1 中心针 2~3 mm 内——端接必须发生在电缆口，否则电缆与端接点之间的走线本身就成了未端接的传输线。
S2R1 · 49.9Ω 1%50Ω 端接
信号在此的变化
把入口节点从「高阻测量点」变成「50Ω 低阻节点」。信号幅度降到源电动势的一半：Vnode = Es·49.9/(50+49.9) ≈ 0.4995·Es。阻抗 50Ω → 50∥(后级高阻) ≈ 50Ω；相位不变；频率不变。
理论公式与计算过程
  • 分压：Vnode = Es · R1/(Rs + R1)，取 Rs = R1 = 50Ω ⇒ Vnode = Es/2。
  • 反射系数：Γ = (R1 − Z0)/(R1 + Z0) = (49.9 − 50)/(49.9 + 50) = −0.001 ⇒ 回波损耗 RL = −20·log₁₀|Γ| = 60 dB。
  • 按 1% 容差取最坏 R1 = 50.4Ω：Γ = 0.4/100.4 = 0.004 ⇒ RL ≈ 48 dB（仍远优于 20 dB 的工程门槛）。
  • 端接对阻带残留的绝对压降（与信号同比例，不改变信噪比）：见 S12 的折叠带复算。
选型依据
判据①匹配题面 50Ω 电缆；判据②让读数与源内阻无关（源内阻从 0 漂到 50Ω，端接后节点幅度只从 Es 变到 Es/2，且这是可标定的常数）；判据③把折叠残留的绝对值压到门限以内。49.9 而不是 50：E96 标准档位，1% 容差下回波损耗已经足够。
⚠ 禁错：不要为了「拿回 6 dB」删掉它——删了幅度翻倍、源阻抗重新变成未知量。真正压住折叠带的是 8 阶 LC 的 −65 dB（S8~S12），不是这一级。
S3D1 · PESD5V0X1BT（SOT-23-3，单路对地）ESD 钳位
信号在此的变化
正常工作时对信号几乎透明：结电容 Cj 只有 pF 级，在 500 kHz 处|Z| = 1/(2πfCj) ≈ 1/(2π·500k·1.5p) ≈ 212 kΩ，远大于节点阻抗 50Ω，分压影响 < 0.03%。静电/过压瞬间则导通，把节点电压钳在安全区。
理论公式与计算过程
  • 结电容旁路影响：|ZCj| = 1/(2πf·Cj)，f = 500 kHz、Cj = 1.5 pF ⇒ 212 kΩ。
  • 对 50Ω 节点的分压误差：Δ ≈ 50/212000 = 2.4×10⁻⁴ ⇒ 幅值误差 < 0.03%（可忽略）。
  • 负向钳位点 = −VF ≈ −0.7 V（二极管正向）；正向钳位点 = 器件击穿电压档（> 5 V）。
选型依据
选它是因为 Cj 只有 pF 级：普通 TVS 是几十 pF，会在 500 kHz 引入不可控的相移与增益漂移。当前接法是单通道对地钳位（C1→信号节点、A→AGND、C2→NC），不是 SRV05-4 的四通道双轨钳位。
⚠ 边界：钳位电平高于运放 U1A 的绝对最大输入（V+ +0.5 V = 5.5 V），挡得住 ESD、挡不住持续过压。竞赛场景（信号源输出可预期）可接受。另：该件的「型号↔符号↔封装」三者尚未完全对齐（待确认项），本文只讲接法与角色，不引用具体 datasheet 数值。
S4C1 100nF (C0G, 1206) + R2 10kΩ隔直 + 输入高通
信号在此的变化
C1 把信号源的直流分量挡在门外，只放交流通过；R2 给运放同相端提供一条到 VBIAS 的直流回路，于是「交流信号骑在 1.650 V 上」进入缓冲器。这一级把信号从「源域」搬进「单电源域」，直流工作点被重新定义为 VBIAS。频域上形成一个一阶高通：fc = 159 Hz。
理论公式与计算过程
  • 高通拐点：fc = 1/(2π·R2·C1) = 1/(2π × 10×10³ × 100×10⁻⁹) = 1/(6.2832×10⁻³) = 159.15 Hz。
  • 带内误差（分析带下限 10 kHz）：ωRC = 2π×10⁴×10⁻³ = 62.83；|H| = ωRC/√(1+(ωRC)²) = 62.83/62.838 = 0.99987 ⇒ −0.001 dB。
  • 与下限的余量：10 kHz / 159 Hz = 63×（拐点远在带外，带内平坦）。
  • 为什么取 10 kΩ：既要「不加载源」（≥50Ω 的 200 倍）又要「不被运放偏置电流顶偏」——OPA2197 的 Ib = ±5 pA，在 10 kΩ 上只产生 50 nV 失调。
选型依据
C1 用 C0G 而不是 X7R：X7R 的容值随电压/温度漂移，会在拐点附近引入不可标定的相移；用 1206 是 C0G 做到 100 nF 的封装代价。R2 取 10 kΩ 是「高阻不加载 / 低阻不被 Ib 顶偏」的折中。
⚠ 这一级的直流回路是必须的：没有 R2，运放同相端没有直流通路，会漂到轨。
S5JP1 · 0Ω可拆断点
信号在此的变化
装上时等于一根导线，信号原样通过；拆掉后前半段（端接/隔直）与后半段（缓冲/滤波）电气解耦，可以单独给任一半注入测试信号。
理论公式与计算过程
  • 0Ω 跳线的直流压降 = 0；寄生电感 < 1 nH，在 500 kHz 处 |Z| < 3 mΩ，可忽略。
选型依据
调试基础设施：扫频标定时可以把 AFE 一分为二，分别验证「端接是否生效」与「滤波器是否对」。成本 ¥0.01，但把「整链猜」变成「分段测」。
⚠ 另一处同类断点是 JP2（ADC 前，见 S16）。两个断点把 AFE 切成三段。
S6U1A · OPA2197 半片（跟随器 G=1）单位增益缓冲
信号在此的变化
高阻输入、低阻输出：电压幅度不变（G=1），但把信号从「50Ω 测量点」搬到「能驱动容性负载的源」。输出阻抗从 50Ω 降到运放闭环输出阻抗（< 1Ω @低频）。相位在带内基本为 0，仅在高频有轻微滞后。
理论公式与计算过程
  • 跟随器：Vout = Vin，增益 = 1（U1.1 OUT 与 U1.2 −IN 直连）。
  • 输入偏置电流影响：Vos,err = Ib·Req = 5 pA × 10 kΩ = 50 nV（可忽略）。
  • 容性负载稳定：R3 = 49.9Ω 把 LC 输入端（C2 = 6.2 nF，在 1 MHz 处 |Z| = 25.7Ω）与输出隔离，避免直接驱动大容性负载引起振铃。
选型依据
为什么必须有这一级：① 端接节点是高阻测量点，直接挂 LC 会让 LC 的输入阻抗与 R1 分压，端接值不再精确；② LC 输入端的 C2 在 MHz 处只有几 Ω，直接挂电缆/TVS 会被容性扰动。为什么刻意不加增益：uJ 是 ±50 mVpk 的大干扰，若先放大 ×8 再滤波，运放会被推入非线性区产生 IM3，而 IM3 产物落在分析带内、滤波器在它后面根本去不掉。所以顺序被钉死为：缓冲 → 滤波 → 放大。
⚠ OPA2197 选型理由：GBW = 10 MHz、压摆率 ≈ 20 V/µs、失调 < 250 µV、单电源 4.5~36 V、轨到轨 I/O、静态电流 ≈ 1 mA/通道。对 500 kHz 带宽有 20× 余量。
S7R3 · 49.9Ω 1%梯形源端阻抗 + 容性隔离
信号在此的变化
与后级 LC 一起构成双端接梯形的源端 50Ω。信号在此进入滤波器，幅度基本不变（R3 与 LC 的输入阻抗分压），但滤波器的形状由它定义。
理论公式与计算过程
  • 双端接条件：源端阻抗 R3 = R4 = 50Ω，与滤波器特征阻抗 R0 = 50Ω 匹配。
  • 端阻抗对滤波器的影响：把 R3 从 49.9 改成 59Ω（仿真 O1）⇒ 阻带改善 0.94 dB，但通带起伏从 0.39 dB 恶化到 0.60 dB —— 方向反了，故否决。
  • 容性隔离：C2 在 1 MHz 处 |Z| = 25.7Ω；串入 49.9Ω 后，运放看到的负载从「纯容性 25.7Ω」变成「49.9 + 25.7∠−90°」，相位裕度不再被容性负载吃掉。
选型依据
它同时是两个角色：① 双端接梯形的源端阻抗（与 R4 配对，改它 = 改滤波器）；② 把 U1A 输出与梯形的大容性输入隔开。E96 标准值 49.9Ω、1%。
⚠ 禁错：不要把它当「隔离电阻」随手改成 0Ω —— 那会同时废掉匹配与源阻抗。
S8L1 4.7µH + C2 6.2nF8 阶 LC 第 1 节
信号在此的变化
串臂 L1 对高频呈高阻（|ZL| = 2πfL），并臂 C2 把漏过 L1 的高频成分泄入 AGND。这一节把转折频率以上的成分开始往下压。带内幅度几乎不变，高频段幅度快速衰减、相位滞后。
理论公式与计算过程
  • 巴特沃斯原型 g 值（n = 8，从源端数）：g₁…g₈ = 0.3902, 1.1111, 1.6629, 1.9616, 1.9616, 1.6629, 1.1111, 0.3902。
  • 元件换算（R₀ = 50Ω、fc = 660 kHz、ωc = 2πfc = 4.1469×10⁶ rad/s）：
  • 串臂电感：Lk = gk·R₀/ωc；并臂电容：Ck = gk/(R₀·ωc)。
  • L1 = 0.3902 × 50 / 4.1469×10⁶ = 4.705 µH ⇒ 取 4.7 µH（偏差 −0.1%）。
  • C2 = 1.1111 / (50 × 4.1469×10⁶) = 5.358 nF ⇒ 图纸取 6.2 nF（+15.7%，见 note）。
选型依据
L1 选 XRCD54-4R7M 绕线电感：4.7 µH 档、额定电流远大于本电路峰值（见下），屏蔽型（XRCD）减少与相邻电感的互感。C2 用 C0G 0805：容值不随电压/温度漂移，否则滤波器的转折频率会随信号幅度漂移，破坏标定。
⚠ C2 = 6.2 nF 是按 17 点标定残差择优出来的值（理想 5.36 nF，在售档位里 6.2 nF 使标定残差最坏值最小）。不要按巴特沃斯标准表核对，这套 LC 值是「在售档位 + 标定残差」双约束下的拟合值，必须靠 ABCD 级联复算背书。
S9L3 22µH + C4 10nF8 阶 LC 第 2 节
信号在此的变化
同上：串臂继续挡高频，并臂继续泄放。累积衰减以约 6 dB/倍频程（每节）递增，在阻带内 8 节合起来是 48 dB/倍频程。
理论公式与计算过程
  • L3 = g₃·R₀/ωc = 1.6629 × 50 / 4.1469×10⁶ = 20.05 µH ⇒ 取 22 µH（+9.7%）。
  • C4 = g₄/(R₀·ωc) = 1.9616 / (50 × 4.1469×10⁶) = 9.460 nF ⇒ 取 10 nF（+5.7%）。
  • 单节转折：f = 1/(2π√(LC)) = 1/(2π√(22µ×10n)) = 1/(2π×4.69×10⁻⁷) = 339 kHz（该节的自谐振点，实际转折由整链共同决定）。
选型依据
L3 用 CD54-220M（22 µH 档，与 L5 同料号，统一 BOM）；C4 用 C0G 0805。偏差 +9.7% 是「E24 在售档位 + 整链复算」的折中，不是随手取的。
⚠ PCB 硬约束：四个电感必须正交摆放（相邻两两垂直），否则互感会把滤波器的实际响应拉偏，而 DRC 不会报错。
S10L5 22µH + C6 9.1nF8 阶 LC 第 3 节
信号在此的变化
同上。这一节的电容 C6 是整链里偏离理想值最大的一颗（理想 8.02 nF → 实取 9.1 nF），代价是带内约 375 kHz 处出现极浅的凹陷（< 0.15 dB），由 17 点标定吸收。
理论公式与计算过程
  • L5 = g₅·R₀/ωc = 1.9616 × 50 / 4.1469×10⁶ = 23.65 µH ⇒ 取 22 µH（−7.0%）。
  • C6 = g₆/(R₀·ωc) = 1.6629 / (50 × 4.1469×10⁶) = 8.019 nF ⇒ 择优取 9.1 nF（+13.5%）。
  • 择优依据：把 C6 从 10 nF 改到 9.1 nF 后，17 点标定残差的最坏值从 5.22 mV 降到 2.97 mV（判据 5 mV，n = 400 蒙特卡洛）。
选型依据
C6 取 9.1 nF（GRM2195C1H912JA01D，C0G 0805）是仿真择优结果：原值 10 nF 时最坏残差已超判据（5.22 mV > 5 mV），必须改。这不是「画错了」，而是「在售档位里能买到的最优解」。
⚠ 这一条是「为什么不能按标准表核对」的最佳例证：8.02 nF 在 E24/E96 里都不好买，9.1 nF 是 E24 档位。
S11L7 12µH + C8 1.8nF8 阶 LC 第 4 节（末节）
信号在此的变化
末节并臂 C8 与负载端 R4 一起构成梯形末端。经过 4 节累积，≥1.5 MHz 的成分被压到 −65 dB 量级（相对通带）。
理论公式与计算过程
  • L7 = g₇·R₀/ωc = 1.1111 × 50 / 4.1469×10⁶ = 13.39 µH ⇒ 取 12 µH（−10.4%）。
  • C8 = g₈/(R₀·ωc) = 0.3902 / (50 × 4.1469×10⁶) = 1.882 nF ⇒ 取 1.8 nF（−4.4%）。
  • 整链 ABCD 级联复算（R3 = R4 = 49.9Ω，含 C7 隔直）：
  • 　|H| @10 kHz = 0.50015（−6.018 dB，双端接固有插损 = 1/2）；
  • 　|H| @500 kHz = 0.49897（−6.039 dB）⇒ 带内 10k~500k 起伏 0.0025 dB；
  • 　|H| @1.5 MHz = 0.00054（−65.33 dB）⇒ 归一化阻带 −64.3 dB，判据 ≤ −42.5 dB，余量 21.8 dB。
选型依据
L7 用 XRCD54-120M（12 µH）；C8 用 C0G 0805 1.8 nF。末节的值决定了阻带起始的陡度，偏差必须靠整链复算确认。
⚠ 「双端接 ×0.5」是梯形固有的插损：50Ω 源 + 50Ω 负载的匹配网络中，只有一半的源电动势落在负载上。这不是缺陷，是 50Ω 系统的定义。
S12C7 10µF + R4 49.9Ω隔直终接
信号在此的变化
R4 是梯形的负载端阻抗（终接），与 R3 配对；C7 串在 R4 入地腿上，对交流几乎透明、对直流断路。于是：滤波器形态不变，但梯形内的直流电流归零。
理论公式与计算过程
  • 直流：电感在直流上短路 ⇒ 若不隔直，R3 → L1…L7 → R4 是一条纯直流通路，IDC = VBIAS/(R3+R4+ΣDCR) ≈ 1.650/(49.9+49.9+小量) ≈ 16.5 mA。
  • 隔直后：IDC = 0；+5V_A 的真实负载从 ~18.5 mA 回落到 ≈ 2 mA。
  • C7 在 500 kHz 的阻抗：|Z| = 1/(2π×500×10³×10×10⁻⁶) = 31.8 mΩ ⇒ 对 49.9Ω 终接的影响 < 0.07%。
  • 对照（若 C7 误装 10 nF）：|Z| = 1/(2π×500×10³×10×10⁻⁹) = 31.8 Ω ⇒ 终接阻抗变成 49.9 + j(−31.8)，相位与幅度都错，滤波器形状被破坏。
选型依据
C7 取 10 µF：既要把 16.5 mA 的直流白流掐断（否则电感白发热、占掉 Isat 余量 33%），又要在 500 kHz 处阻抗足够小以不干扰终接。10 µF 同时满足两条（31.8 mΩ ≪ 49.9Ω）。

理论公式与计算过程
  • 增益：G = 1 + R6/R7 = 1 + 24.9×10³/3.57×10³ = 1 + 6.975 = 7.975。

  • 　虚短 V₋ = V₊ = Vin；虚断 ⇒ (Vout − V₋)/R6 = (V₋ − VBIAS)/R7；
  • 　⇒ Vout = Vin·(1 + R6/R7) − VBIAS·(R6/R7)；
  • 　⇒ Vout − VBIAS = (Vin − VBIAS)·(1 + R6/R7)。

构成一个 3.39 MHz 一阶低通：对 500 kHz 通带几乎无影响（−0.02 dB），但把 ADC 采样瞬间的电荷尖峰（kickback）就地吸收，不让它打到运放输出上。
理论公式与计算过程
  • 低通拐点：fc = 1/(2π·R11·C10) = 1/(2π × 100 × 470×10⁻¹²) = 3.386 MHz。

选型依据
