## 2. 根因一：EVK1 符号本体罩住内侧引脚列（阻塞 19 ERROR + ≈40 叠旗）

`EVK1` = `LCKFB-LSPI-SkyStar-STM32F407VGT6-PRO`@(780,515)，Device `5064d5360e2055fe`（立创公共库，无项目内符号副本）。

引脚分布（实测）：左列 **x=370**（外）与 **x=510**（内）；右列 **x=1040**（内）与 **x=1180**（外）。

在 `EVK1:38`(510,425) 上做定向实验，`connect` 预检同时返回两条 ERROR：

```
pin-exit-direction : pin 38 outward rotation 0° requires its first wire segment to leave outward
                     segment 0 (510,425)->(480,425) does not
wire-through-body  : wire segment 0 (510,425)->(480,425) enters component body
                     （原桩 (510,425)->(540,425) 同样被判进本体）
```

即：**往右、往左都被判进本体** —— 符号的大矩形/实拍图把 x510 与 x1040 两列整列罩住，这两列上的**任何**桩线都不合法。x370 / x1180 两列在体外，所以它们的桩线正常。

⇒ 19 条 `wire-through-body` 与约 40 条 `marker-overlap` 都是这一根因，**靠挪端口/改桩长修不掉**。

**处置建议（未执行）**：为 EVK1 另建一个符号变体（去掉/缩小罩住内侧列的那块图形），再 `sch rebind-symbol` 事务式换绑（候选先建后读、回读绑定与 `uniqueId`、失败看 `phase`）。注意立创**系统库不可写**，须在项目库建副本。
