## §1 修订版"军规"逐条判定

| 条目 | 判定 | 成立的条件 / 必须的修正 |
|---|---|---|
| 一.1 −in 对地寄生 = 最主要因素 | **成立** | 条件是 `Rf‖Rg ≫ Ro`（中高阻反馈网络）。代价 `θ=arctan(2π·f_c·Rf‖Rg·C_in)`；**它是唯一不能靠"隔离"解决的一项** |
| 一.2 输出对地寄生 = 第二主要 | **成立，但可豁免** | 反馈点取在输出脚 + `R_iso` 串在之后 ⇒ `C_load` 整条出环，这条不再适用。**β=1（跟随器）时它可能升到第一** |
| 一.3 单电源 −in 与 V_ref 间不接电容 | **成立** | `V_ref` 交流上即地 ⇒ 与"−in 对地电容"等价。**但 V_ref 自己的去耦电容必须留**（挂在分压器那一头）；错的是把电容挪到 −in 侧 |
| 一.4 **（原文空着）** | **建议填这一条** | 见 §1.1 |
| 二.1 −in 区域底面挖空 + 最外焊盘离 GND 30~50 mil + 多层全挖"一劳永逸" | **方向对，三处要修** | 见 §1.2（层次 / 范围 / "一劳永逸"的前提） |
| 二.2 −in **和 +in** 走线都不与输出平行/靠近 | **成立，且你补的 +in 比原句更硬** | 两个节点的机制**完全不同**，见 §1.3：−in 是"改补偿"，+in 是"**正反馈**" |
| 二.3 `Rf`/`Cf` 贴 −in、环路面积最小、走线最短 | **成立** | 节点铜面积就是电容的载体；`Cf` 必须与 `Rf` 同侧同处，否则补偿失效 |

### 1.1 一.4 建议填什么（按优先级）

1. **电源去耦不是"寄生"**：正/负电源脚**必须**就近对地去耦（这是必需品，跟 1、2 两条方向相反）；去耦失效是自激的经典诱因之一。
   —— 这是原清单**最大的缺口**，建议作为 4。
2. （备选）**输出→+in 不得有耦合**（本质是正反馈）—— 已由二.2 覆盖，但值得在原理图层也写一句。
3. （备选）**大容性负载必须串隔离电阻**（`R_iso` 或 RC 缓冲）—— 这条在原理图阶段就能解决，比"躲寄生"更强。

### 1.2 二.1 的三处修正

| 原话 | 修正 |
|---|---|
| "**多层全部挖空**，一劳永逸" | **不要多层全挖**。① 四层板的内层是参考平面，挖洞 = 开槽，别的信号回流被迫绕行；② **双面板底面只贡献 ~0.05 pF/mm**，挖了只值 0.1–0.5°，却拿掉了一块屏蔽。**只退"同层"**（−in 所在层） |
| "反相输入端覆盖面积（负反馈网络那几个焊盘围成的区域）底部挖空" | 定义基本对，但精确说法是：**让禁铺/退让覆盖"−in 网络的全部铜"**（−in 脚 escape + 到 `Rf`/`Rg`/`Cf` 的每段 + 它们与 −in 相连的焊盘），再**外扩 30~50 mil**。围成的区域里若含 `Rf` 的输出侧焊盘（低阻、不在乎）无妨，但**不许漏掉任何一段 −in 铜** |
| "最外焊盘与 GND 间隔 30~50 mil" | **数值合理**（30 mil=0.76 mm、50 mil=1.27 mm，约为 DRC 下限的 10~17 倍，边沿耦合按比例降 2~3 倍；再往外收益递减且开始丢屏蔽）。**但"一劳永逸"有前提**：收益 ∝ 节点本身的长度/面积 ⇒ **先把节点做短，再谈退让**；且**挖空前必须看背面**——被挖掉的地铜同时也是屏蔽，背面若有强信号，等于给它装了个天线 |

### 1.3 二.2：为什么"+in"这一半更硬（两个节点机制不同）

| | −in 与输出耦合 | **+in 与输出耦合** |
|---|---|---|
| 电路上等价于 | 给 `Rf` **并一个 `Cf`** | 给"净反馈"减掉一项：`净反馈 = β − k` |
| 方向 | **补相位裕度**（改的是补偿） | **正反馈**（吃掉负反馈） |
| 危害 | 量值不可控 ⇒ 改掉你算好的响应/噪声；强信号注入高阻节点 | **k ≥ β 就锁定/振荡**。高增益档 β 小 ⇒ **只需百分之几的耦合就要命**（×16 档 β=6.25%） |
| 结论 | 尽量远离（一级） | **零容忍**（比 −in 更严） |

> 本板对照：`U1B` 是**非反相 ×16**（β=1/16），`+in` 恰好又是信号入口 —— 所以二.2 的后半句在本案里比前半句更要紧。

## §2 设计流程（六阶段，每阶段带判据）

### 阶段 0 · 需求 → 器件门槛（先算，别画）

| 项 | 判据 | 说明 |
|---|---|---|
| 增益配置 | 定 `NG = 1+Rf/Rg`（同相）或 `Rf/Rg`（反相） | 后面所有账都依赖它 |
| 带宽 | `f_c = GBW/NG ≥ 10×f_max` ⇒ 不用标定；`f_c ≈ f_max` ⇒ **必须标定**（本项目就是后者） | 本板 625 kHz vs 500 kHz ⇒ 靠 17 点标定吸收 |
| 压摆率 | `SR ≥ 2π·f_max·V_pk`，留 ≥2× 余量 | 本板运放只见 ≤62 mVpk ⇒ 余量极大 |
| 噪声 | `e_n·√BW·NG` ≤ 精度预算的 1/3 | 本板 1270× 余量 |
| 器件类 | 电压反馈 vs 电流反馈；单电源范围；输入共模范围 | **CFB 时"−in 不许挂电容"是铁律** |

### 阶段 1 · 相位预算（唯一能把"自激"变成算术的一步）

1. 列**环内所有外部极点**：`−in`（`Rf‖Rg × C_in`）· 输出（`Ro × C_load`）· 电源/地耦合（PSRR 路径）。
2. 每条算 `θ = arctan(2π·f_c·R_seen·C)`，**总和 ≤ 10–15°**（给器件自身留 ≥45–60°）。
3. 反解出可施工的约束：
   - `C_in ≤ tan(θ_max)/[2π·f_c·(Rf‖Rg)]` —— 决定布局能容忍多少走线/铺铜
   - **`Rf ≤ NG·tan(θ_max)/(2π·f_c·C_in)`** —— 决定反馈电阻能取多大
   - `L_trace ≤ (C_in,budget − C_in,device)/c′`（`c′` 见阶段 3）
4. 不满足 ⇒ 三条杠杆：**降 `Rf‖Rg`**（耗流）· **抬 `NG`**（带宽↓）· **加 `Cf = C_in·Rg/Rf`**（多一个极点 + 容差）。
5. 产出：**一张"相位预算表"**（和误差预算同格式，写进图纸注释）。

### 阶段 2 · 原理图（先做"结构"，再谈寄生）

| # | 动作 | 为什么 |
|---|---|---|
| 1 | **反馈点取在输出脚，负载/`R_iso` 接在反馈点之后** | `C_load` 整条出环 —— 比"躲寄生"强一个量级 |
| 2 | −in 上**不允许**出现任何"对交流地的电容"；`V_ref` 去耦电容只挂分压器那头 | 器件 `Cin` 已是最小值，别再加 |
| 3 | `C_in` 大 / `Rf` 必须大 ⇒ 加 `Cf = Cin·Rg/Rf`（TIA 用最平式），**与 `Rf` 同侧** | 抵消环内极点 |
| 4 | **电源脚就近对地去耦**（正、负都是），必要时串小阻隔离 | 原清单缺的第 4 条 |
| 5 | 大容性负载 ⇒ `R_iso` / RC 缓冲 | 同上 |
| 6 | 单电源：`V_ref` 用低阻分压 + 大电容；检查它是否同时是"+in 偏置 + `Rg` 回地点"（第二反馈路径） | 本板 `VBIAS` 正是这种节点 |

### 阶段 3 · PCB 布局（**顺序不能反**）

放置顺序：`Rf`/`Cf` 贴 −in 脚 → −in 节点面积最小 → `+in` 一侧保留地铜 → 走线远离输出/时钟/数字 → 去耦贴脚 → 隔离电阻贴输出脚。

| 判据 | 目标 | 本板实测 |
|---|---|---|
| `Rf`/`Cf` → −in 脚 | **≤3 mm** | `R6` 2.46 ✓ / `R7` **3.67**（越线） |
| **−in 节点铜总长** | **≤3 mm** | **7.05 mm**（差距最大的一项） |
| −in 与输出最近距离 / 平行段 | 越远越好；平行段 ≤5 mm | **1.27 mm（=封装 50 mil 脚距本身）/ 平行 2.1 mm** ✓ 合规 |
| 去耦 → 电源脚 | ≤2 mm | `C14` 2.23 ✓ / `C11` **3.55** |
| 电阻封装 | 短体（0805），不串多颗凑值 | — |
| `c′`（走线电容密度，经验量级） | 微带（对底层平面，1.5 mm 介质）**~0.05 pF/mm**；**同层铺铜边沿耦合 +0.15~0.3 pF/mm**（间隙 0.25 mm 时） | 本板间隙更大 ⇒ 取小值 |

### 阶段 4 · 铜皮与禁铺（最后一步，最容易做过头）

1. **只退同层**：让 −in 网络的全部铜 **离 GND/AGND 铜皮 30~50 mil（0.76~1.27 mm）**。
2. **不要多层全挖**（§1.2）；**不要用一大片禁铺区** —— 会切断地岛（本板 `AGND` 只有 `EVK1.37` 一个出口）。
3. **挖空前看背面**：被挖掉的地铜也是屏蔽。
4. 判据：间隙达标 · 地岛仍连通 · DRC 通过 · **改完重跑阶段 1 的预算表**。

### 阶段 5 · 验证（三层，从便宜的到贵的）

| 层 | 做什么 | 判据 |
|---|---|---|
| 纸面/仿真 | 相位预算表 + 宏模型环路 | 外部极点总和 ≤10–15°；**宏模型只能横向比较** |
| 上板静态 | 空载、输入端端接 50 Ω、**不接源**看输出 | 无**持续正弦**；电源电流不异常偏大（振荡时电流会涨） |
| 上板动态 | 阶跃响应看**过冲/振铃**；扫频看闭环峰值 | 过冲 ≤10%（≈PM 60°）；25% ≈ PM 45°；**持续振荡 = PM ≤0°**；峰值抬升 >2–3 dB 要查 |

### 阶段 6 · 留痕

把"环内极点清单 + 相位预算表 + 实测"写进图纸注释/文档；**改任何 `Rf`/`Rg`/`Cf`/布局都要重跑阶段 1**。
（本板教训：`R6` 24.9k → 53.6k 就动了这笔账：16.4° → 8.8°。）

```

[ ] 2  电源脚就近去耦（正负都做）

```

## §4 本板（G2026 AFE）对照：哪几步做到了、哪几步是缺口

| 阶段 | 现状 | 差距 |
|---|---|---|
| 0 | `U1`=OPA2197（VFB、GBW 10 MHz、SR 20 V/µs）；`U1A` 跟随器、`U1B` 非反相 ×16.0 | — |
| 1 | `U1A`：β=1、`f_c`=10 MHz、**环内无外部极点**（`R3` 隔离）；`U1B`：`f_c`=625 kHz、−in 极点 3.96 MHz ⇒ **θ≈9–10.5°** | 账已在预算内；**未写成表落进图纸注释** |
| 2 | 反馈点取在输出脚 + `R3`/`R8` 在环外 ✓；`VBIAS` 是"第二反馈路径"节点但被 `C13`(10 µF) 压住 ✓ | 反馈网络上**无 `Cf`**（要补是 0.80 pF）；`C11` 去耦 3.55 mm |

| 4 | 现状 `copper.regions`=0（**没用过禁铺**）；同层 AGND 间隙实测 **铜到铜 13–16 mil**；**L2 未挖空** | 目标 30~50 mil ⇒ 需退 +15~35 mil（≈0.4~0.9 mm）；**L2 建议保持不挖**（双面板收益仅 0.1–0.5°） |

## §5 诚实边界与依据

1. 所有相位数字基于**单主极点宏模型**（无真实器件高频极点）⇒ 只能横向比较；真实 PM 是 datasheet 性质，本仓无 OPA2197 datasheet。
2. `Cin 8p+4p`、`Ro 100Ω` 是**模型值/假设**；板侧电容 1–2 pF 是按**实测间隙**推的区间（密度 0.15–0.3 pF/mm 仍是经验值）。
3. 阶段 3 的 `c′` 两档（微带 0.05 / 边沿 0.15–0.3 pF/mm）是**量级估计**，没做场求解。
4. "30~50 mil"是**工程经验区间**（不是定律）：按边沿耦合随间隙单调下降、且再往外收益递减而屏蔽损失增加取的折中。
5. 过冲↔相位裕度的换算（5%≈65°、10%≈59°、25%≈44°）来自二阶系统近似，用于快速判断，不替代扫频。
6. 本轮**未改任何图/板**；§4 的排序**全部未执行**。
