## 2. 三页各做了什么

### INT（4 个连接器，93 → 81 标签）

**清理的冗余标签**（同器件同网、本可并联）：

| 网络 | 原状 | 改法 |
|---|---|---|
| `GND` | H3 的 **6 个脚**（.2~.7）各挂一个地旗 | **母线并联**（x=660 竖线）+ **1 个地旗** |
| `BL_K` | H3 的 **6 个脚**（.38~.43）各挂一个标签 | **母线并联** + **1 个标签** |
| `+3V3` | H3 的 .11/.12 各挂一个旗 | 短线并联 + **1 个旗** |

**跨器件的 ~25 个信号网**（`LCD_D0~D15`、`LCD_CS/WR/RD/RS/RST`、`TP_*`、`AFE_ADC_IN` 等）
**保留标签** —— 它们跨越大半张图，走线反而不可读。

**分区框**：① 核心板（EVK1）· ② 显示与触摸（H3/H4）· ③ 板间互连（J4）。
**说明**：FSMC 16bit 并口映射、I2C 触摸、IM0/1/2 由 PWR 页配置、AGND 单点接地。

### PWR（20 器件，44 → 36 标签）

**改成实体导线的内部网络**：`+5V_RAW`（J3.1→D2.2）、`Q1_G`（Q1.1→R12.2→R13.1）、
`LED_A`（LED1.1→R11.1）、`+3V3`（U3.2/U3.4 两路 VOUT 并联）、`GND`（J3.2/J3.3 并联）。

**分区框**：① 电源输入与防反接 · ② 3.3V LDO · ③ 背光恒流驱动 · ④ 屏接口配置与上拉。
**说明**：肖特基防反接的 Vf、AMS1117 压差、Q1 低边开关与栅极下拉、I2C 上拉与 IM 配置。

### AFE（39 器件，57 → 44 标签）

**清掉 13 个"线已连通、标签纯冗余"的内部网名标签**：
`AFE_TERM` / `AFE_B1_AC` / `AFE_B1_IN` / `AFE_G1_OUT` / `F1~F5` / `AFE_G2_IN` /
`AFE_ADC_OUT` / `AFE_G2_FB` / `AFE_ADC_MON`。
（`AFE_ADC_IN` / `VREF_3V3*` / `VBIAS_1V65` 是跨页信号，**保留**。）

**分区框**：① 输入保护与 50Ω 端接 · ② 一级缓冲与偏置注入 · ③ 基准与偏置 ·
④ 8 阶巴特沃斯抗混叠低通 · ⑤ 二级增益 ×4 与 ADC 驱动。
**说明**：端接的"免费"匹配、单位增益缓冲回路、LC 梯形结构、**增益 1+R6/R7=×4** 的推导。

## 3. 本轮新踩的坑（已回写台账 T-35~T-38）

| 编号 | 事实 | 后果 |
|---|---|---|
| **T-35** | **V4.1.60 起 `sch_PrimitiveWire.modify(id,{line})` 清不掉 `net`**（显式传 `net:""` 也无效） | 想清导线网名只能**删了重建** |
| **T-36** | 给**多段折线**设 `net` → 触发「导线有多个网络名: X、X…」（**每段算一个**） | 要么单段、要么改用净标签；**别给折线设网名** |
| **T-37** | `sch_PrimitiveText.getAll()` 返回对象上 **`value` 读不到**（空串） | 按内容匹配文本不可行 → 按**坐标**匹配 |
| **T-38** | 同器件同网多脚的**母线并联套路**：外侧一根竖/横母线 + 各脚短线 + **一个**旗/标签 | INT 一次消掉 13 个冗余标签 |
