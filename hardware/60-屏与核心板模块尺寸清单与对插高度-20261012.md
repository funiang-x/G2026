### 0.2 竖向堆叠（★ 母座对插层高，本次核心结论）

| 连接 | 组成（标准件配合） | **层高（板面→板面）** |
|---|---|---|
| **屏模块**：底板顶面 → 转接板底面 | J5 母座塑高 **H**（8.5 标准 / 10.1 加高，**待实测**）+ 排针塑胶 **2.5** | **11.0**（H=8.5）/ **12.6**（H=10.1）|
| **核心板**：底板底面 → 核心板（针面） | 双排母塑高 **8.5** + 排针塑胶 **2.5** | **11.0** |
| **核心板**：底板底面 → 核心板底（板背面） | 上式 + 核心板厚 ~1.6 | ≈ **12.6** |

> **推导**（详见 §5）：标准 2.54 排针总长 11.6（焊端 3.1 / 塑胶 2.5 / 插针端 6.0）；插入 8.5 母座到"塑胶面与母座口平齐"时**针尖距孔底还有约 0.4 余量** —— 自洽全插配合。故 **层高 = 母座塑高 + 2.5**。

### 0.3 相对底板面的总堆叠（屏面朝上、核心板吊于下方，均按 H=8.5 档）

```
 屏面（玻璃顶）        ≈ 底板顶面 +14.96   ← 上盖内面 ≥ +15.3
 屏背面                ≈ +12.9（含背胶 0.3 名义）
 转接板顶面            =  +12.6
 转接板底面（排针出针）=  +11.0           ★ 对插层高
 底板顶面              =   0
 底板底面              =  -1.6
 核心板针面            = -11.0 -1.6 = -12.6（核心板面）★ 对插层高 11.0
 核心板底面元件最高点  ≈ -12.6 −（元件高，**待实测**，估 3~4）→ 外壳内底 ≥ -17
```

**外壳内腔总高（暂按 8.5 档 + 元件 4mm + 上下各 0.3~1.0 余量）：约 32.5 ~ 33 mm。**

## §5 母座对插层高（★ 本次核心结论，可直接用于净空计算）

### 5.1 标准件几何（推导基础）

| 件 | 几何 | 说明 |
|---|---|---|
| 2.54 mm 公排针（标准 11.6 mm） | 焊端 3.1 / 塑胶 **2.5** / 插针端 **6.0** | 贴板焊接后，针尖距板面 8.5 |
| 2.54 mm 母座（8.5 档/10.1 档） | 塑高 8.5 / 10.1；孔径与 6.0 插针配套 | 焊盘侧针脚穿板 |

**配合关系（全插到底时）**：插针 6.0 全部没入母座孔；**排针塑胶面与母座开口面齐平**；针尖距孔底尚有 ~0.4 余量。
⇒ **对插层高（板面 → 板面）= 母座塑高 + 2.5（排针塑胶）**。

### 5.2 屏模块（底板顶面 → 转接板底面）

```
        屏 55.05×84.50×2.06（居中贴装）
   ┌──────────────────┐
   │ 转接板 98.70×56  │ ← 底面出针（30pin 两排）
   └───────┬──────────┘
       排针（塑胶 2.5 + 插针 6.0）         层高 = J5 塑高 + 2.5
   ┌───────┴──────────┐
   │ J5 母座（8.5 或 10.1）│
   │ 底板 1.6          │
   └──────────────────┘
```

- **H=8.5（标准款）⇒ 层高 11.0 mm**；**H=10.1（加高款）⇒ 层高 12.6 mm**。
- v4 外壳脚本现值 `adapter_z=12.0` 介于两者之间（口径：J5 座高 ~10.1 + 排针塑体）→ **拿到实物以 §8 #1/#2 定案**。

### 5.3 核心板（底板底面 → 核心板）

- 母座 8.5 档（工程建议）⇒ **层高 11.0 mm**；核心板板厚 ~1.6 ⇒ **核心板底面距底板底面 ≈ 12.6 mm**。
- **核心板侧对插几何已闭合**（针/座行距均 2.54 ✓）；唯一变量是核心板朝下元件的最高点（Type-C 等）。

### 5.4 30pin 排距的双源复核（本次新证据）

对同一接口用**两个独立源文件**解出同一几何：

| 源 | 解出 | 结果 |
|---|---|---|
| Altium `.pcbdoc`（1000 亮度版） | P_Head_2x15 全部 32 焊盘：奇数脚 Y=3071.1、偶数脚 Y=3275.8 mil | 排距 **204.7 mil = 5.199 mm** |
| 立创工程 `.epro2`（同款恒流版） | FOOTPRINT `P_Head_2x15` 焊盘 1–30 局部坐标：Y = 0 / −204.7245 mil；另 2 孔间距 1300 mil | 排距 **204.7245 mil = 5.2 mm** |

⇒ 5.2 mm（公制）**double-confirmed**，不是笔误；与 J5 的 2.54 mm 行距**不匹配**，装配方式待实物核（§8 #4）。

## §7 建模基准（坐标与方向约定）

- **原点**：底板框 bbox 左下角（板坐标）；单位 mm。
- **X**：沿底板 80.25 方向（右）；**Y**：沿底板 100.25 方向（上）；**Z**：从底板顶面起算，向上为正（屏在上），向下为负（核心板在下）。
- 屏/转接板以 **J5 中心 (38.86, 82.85)** 为基准：转接板宽 56 居中于 J5 的 X；转接板沿 −Y 外伸 11.5（全板长 98.7）。
- 屏在转接板上居中：屏长 84.50 沿转接板长 98.7（两端各留 7.10），屏宽 55.05 沿转接板宽 56（两侧各留 0.475）。
