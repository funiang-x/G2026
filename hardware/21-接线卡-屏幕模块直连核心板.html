G2026 台面 bring-up · 26 根杜邦线 · 配模块实物照片 + 核心板实物图 · 2026-10-02

三句话看懂怎么接
  1. 模块侧：排针 2×15，每列两个孔。丝印上排是 CS WR RST D01 D03 … IQR GND（奇数脚 1,3,5…29），下排是 RS RD D00 D02 … BL 3V3（偶数脚 2,4…30）。
  2. 核心板侧：丝印名印在背面，丝印面朝上时 P1 在右、P2 在左；每一行两个孔，名字从左到右 ↔ 孔从左到右。
  3. 对上就行：例如模块 CS → 核心板 D07。26 根里 21 根在 P1、5 根在 P2。

4 · 同一列两个孔怎么分（唯一需要你现场确认的一步）

已确定：每列两个孔 = 一对信号（CS/RS、WR/RD、RST/D00…），丝印上排 = 奇数脚、下排 = 偶数脚，两列都自 CS/RS 端起算。这是从转接板原理图（pin1=CS、pin2=RS、pin3=WR、pin4=RD、pin5=RST、pin6=D00、pin7=D01、pin8=D02…pin21=D15、pin22=T_BUSY(空位)、pin29=GND、pin30=3V3）与你的照片双向对出来的。
⚠️ 2026-10-04 更正：这里原来写的是「D01/D00 一对、pin6=空、pin8=D00」，那是把下排读高了一列；正确是 RST 挨着 D00、D15 挨着空位。

还剩一个我没法从资料里读出来的点：丝印上排那一行名字，贴着的是靠外（离丝印远）还是靠里（离丝印近）的那个孔。转接板只给了 Altium 二进制工程 + 一张镜像机构图，这一层对应读不出来。

按最自然的画法先这么接

每个丝印名都紧挨着它自己那一排孔印 —— 所以：丝印上排（CS/WR/RST/D01…）= 靠外那一排孔；丝印下排（RS/RD/D00/D02…）= 靠里那一排孔。（靠外 = 离丝印远、靠板边的那排。）

上电前用最右一列 30 秒确认（零风险）

  1. 只接一根：核心板 GND → 模块最右列的上排孔（丝印 GND 那个）。3V3 先不接。
  2. 再把核心板 3V3 → 同列的下排孔（丝印 3V3 那个）。
  3. 关灯看背光：
    • 背光亮 ⇒ 上排 = GND、下排 = 3V3，读法正确，其余 24 根照 §2 表接。
    • 背光不亮 ⇒ 读法反了：立刻断电，把这两根对调，并且其余所有列也按「上排当偶数脚」接（即 §2 表里左右两栏互换）。

为什么这样试是安全的：3V3 与 GND 只在这一列相邻。若接反，模块内部 3V3 与 GND 之间只有去耦电容，直流不成回路，不会短路；模块只是处于反压状态 —— 所以一看不亮就立刻断电，别停在那儿。想更保险就在 3V3 那根里串一个 1kΩ（电流钳到 3mA，背光会很暗，要关灯看）。

5 · 上电顺序

  1. 先断电插完所有杜邦线。GND 建议接两根（P1-39 + P2-37）到模块同一 GND 脚，降低回流阻抗。
  2. 核心板经 Type-C 供电。
  3. 上电后先看背光：背光应该亮（栅极被 R7 上拉，见 §7-①）。不亮先查 3V3 / GND 有没有插实。
  4. 烧固件后，屏出现雪花就说明初始化成功（厂家通用说明：MCU 屏初始化完会是雪花状，不用等刷颜色）。
  5. 跑一次 I²C 扫描，扫到 0x38 = SCL/SDA 落点全对。扫不到先查 §7-②。

四段，从「不烧任何东西」到「看画面」。每项都给了判据 —— 按顺序做，别跳。

阶段 0 · 断电，万用表（先做这个，不烧任何东西）

② 上电前测有没有短路（电阻档 20k/200k）—— 黑笔核心板 GND、红笔核心板 3V3：

  • 正常：读数先小、然后往上爬（给模块去耦电容充电），最后几百 kΩ 以上。

③ 26 根逐根回对（一支笔固定模块的脚，另一支点核心板对应孔 → 应响；点相邻的孔 → 应不响）。按出错代价从高到低：

  1. 电源 2 根：GND→P1-39、3V3→P1-38
  2. 并口控制 5 根：CS→D07、RS→D11、WR→D05、RD→D04、RST→B01
  3. 触摸 2 根 + 背光 1 根：SCK→B10、MOSI→B11、BL→B00
  4. 数据 16 根：D00→D14 D01→D15 D02→D00 D03→D01 D04→E07 D05→E08 D06→E09 D07→E10 D08→E11 D09→E12 D10→E13 D11→E14 D12→E15 D13→D08 D14→D09 D15→D10

④ 相邻信号不能短路 —— 测模块上相邻两脚（如 D00 ↔ D01）→ 必须不响。杜邦线插歪最容易在这里出事。

阶段 1 · 上电，先不烧固件

  • 只看背光：应该亮（栅极被 R7 上拉）。不亮 → 别怀疑固件，回阶段 0 的 ①②。

7 · 三个注意项

① BL 脚 = 控制脚（已从转接板原理图定案，不用测）

转接板原理图（docs/TK035F5687_9629_整理资料…/05_硬件转接板资料/通用亮度转接板原理图及PCB/TK035F5501_转接板.pdf）里：30-pin 的 BL 脚网络名就叫 BL_CTR（CTR = control）；板上 Q1 = SI2302（N 沟道 MOS），栅极接 BL_CTR、漏极接 LED-（屏背光 38~43 脚 K1~K6）、源极接 GND；栅极经 R7 = 10K 上拉到 3.3V；屏 44 脚 A（背光阳极）在板内直接接 3.3V。

⇒ BL 就是一根栅极信号线，接 B00 安全；背光电源不用外部供（这就是 §1 里那两个「背光」白座本次不用的原因）。与固件注释「PB0 高 = 背光亮」一致。

⇒ 上电到固件跑起来之前，背光本来就是亮的（PB0 复位后浮空，栅极被上拉），不是故障。

② 触摸：不是漏接线，是台面缺一颗上拉电阻（2026-10-02 已定论）

固件里的 I²C 全总线扫描（0x08~0x77 共 112 个地址）实测一个器件都不应答 —— 这排除了"IC 型号不对"。根因查到了厂家例程（02_STM32例程/TK035F9629_ST7796版/STM32_16位并口_标准库_电容触摸/project/bsp/touch/touch_CTP.c）：

线厂家例程的配置例程注释原话
SCL（PB13）GPIO_Mode_Out_PP 推挽"由于只工作在主机模式……所以 SCK 直是输出模式，不用串电阻"
SDA（PB15）GPIO_Mode_Out_OD 开漏"硬件电路中一般在 SDA 信号线上接一个电阻后再接 VCC"

⇒ 厂家例程用软件模拟 I²C，SCL 推挽驱动（能主动拉高）所以不需要上拉；只有开漏的 SDA 要上拉 ⇒ 模块/转接板也只给 SDA 放了上拉（与 2026-09-29 实测吻合：MOSI 有上拉、SCK 只读到 2V）。

而本工程走 STM32 硬件 I²C2 —— SCL/SDA 都是开漏（AF4），两路都必须外部上拉。SCL 拉不起来 ⇒ 时钟线不起 ⇒ 总线不通。

修法：模块 SCK 脚（或核心板 PB10）↔ 3V3 补一颗 4.7k。SDA 侧模块自带；再补一颗也无妨（并联 ≈2.35k，仍在 I²C 合规区 2.2k~10k）。

先做这一步：别用电阻档测（2026-10-02 已踩坑）

⚠️ "断电量 SCK→3V3 的电阻"这个测法不成立。实测：红黑表笔互换得 8.4k / 14k 两个不同的值 —— 两个方向读数不同就说明路径里有半导体结（ESD 保护二极管），不是电阻，读数没有意义。

正确测法 = 上拉的"定义"：把线拉低 → 松开 → 看它能不能自己回到高。（有上拉 ⇒ 回 1；没上拉 ⇒ 停在 0。只有"松手后能自己回高"才证明有源在拉它 —— 光看稳态电压会被悬空脚骗。）

固件已经替你做了这个测试（bsp_touch.c 的 line_has_pullup()），实测结果：

[I] [TOUCH] 两条线都有上拉（拉低后能自己回高）

⇒ 上拉不是问题，这条排除。

那问题在哪：看失败模式

[W] [TOUCH] 首次读取失败：State=0x20(READY) ErrorCode=0x00000020(TIMEOUT)
失败模式含义
NACK（AF=0x04）总线时序合法、器件不应答 ⇒ 没供电 / 被 RST 按住 / 地址不对
TIMEOUT（0x20）← 实测是这个主机自己的波形都没走完 ⇒ 线序 / 引脚复用 / 从机拉死时钟

已知：接线映射对（24=SCL、26=SDA）、型号地址对（0x38）、上拉有、两线没被拉死 —— 却 TIMEOUT。按这个顺序查：

  1. 把 SCK(模块第 24 脚) 与 MOSI(第 26 脚) 两根对调，重跑（10 秒，最可能）
  2. 触摸 FPC 是否插到位；触摸 IC 是否供电（FPC 第 1 脚 VCC 对 GND 应有 3.3V）
  3. 触摸 RST（FPC 第 2 脚）是否被拉低

对调之后：换回去

对调 SCK/MOSI 后，错误码从 0x20(TIMEOUT) 变成 0x200。查源码 Drivers/STM32F4xx_HAL_Driver/Inc/stm32f4xx_hal_i2c.h:172：#define HAL_I2C_WRONG_START 0x00000200U（"错误的起始位"）。

WRONG_START 正是 SCL/SDA 接反的典型特征 ⇒ 先把线换回原样（SCK → B00、MOSI → B11）。换回后如果错误码变成 AF(0x04 NACK) ⇒ 说明总线时序已经通了，问题就纯在器件侧（FPC 插到位 / VCC / RST）。

顺带：界面诊断已加（见 §6 阶段 3）

屏左上角会显示 fps 与 touch x,y，手指按下时屏上还有个红点跟着。用它一眼看出"屏在刷 / 触摸落点在哪。

③ 适配板 IM 档位 + 四根 RGB 同步脚

  • IM 必须 = 010（8080-16bit），照片里位宽表 16 那一行就是 0 1 0 ✓。断电复核：一支表笔固定 30-pin 的 3V3 脚，另一支依次点 Parallel/SPI 表旁那 3 组焊盘，只响 1 次即正确。
  • DE / PCLK / VSYNC / HSYNC 四根不能悬空，规格要求接 IOVCC1 或 GND（DE 必须为低）。照片看这几处元件未焊 → 建议补锡桥接地。悬空的 CMOS 输入对 mV 级 AFE 是白送的噪声源。

8 · 台面 vs 底板（会造成现象差异）

  • 底板的 33Ω FSMC 串阻（R22~R39） 台面没有 → 杜邦线务必短，否则 111ns/字的 16 位并口容易振铃。
  • 底板的 4.7k I²C 上拉（R15/R16） 台面没有 → 见 §7-②。
  • 底板的 1k 背光串阻（R12） 台面没有 → 直连 PB0（栅极无电流，无风险）。
  • AFE / 电源 / 基准部分本次完全不接；ADC 相关脚（A01、C04）保持悬空。
