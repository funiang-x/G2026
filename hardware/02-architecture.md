## 3. 前端 v3 信号链（逐级职责与电平预算）

```
BNC ─ TVS(≤5pF) ─ 50Ω端接(1%) ─ AC耦合100nF/10k ─ ►BUF1（OPA2197半A，G=1）
                                                       │ 50Ω 串联端接电阻
                                                       ▼
                        LC 8阶巴特沃斯 fc=800k（50Ω 系统，双端接，L/C E24 值见复算报告 §2）
                                                       │ 50Ω 负载电阻(1%)
                                                       ▼
                              AC耦合100nF/10k ─► GAIN（OPA2197半B，同相×4，+in偏置1.65V）
                                                       │ 100Ω + 470pF(C0G)
                                                       ▼
                                                    ADC1（fs=2.0MSPS）
1.65V 偏置轨：REF3033(3.3V=VREF) → 10k/10k 分压 → 10µF 去耦 → 10k 偏置电阻喂两级 +in
              （ratiometric：VREF 漂移对幅值测量自动抵消；自检走备用 ADC 通道采 1.65V）
```

**逐级"为什么"（v3 的主见所在）：**

| 级 | 职责 | 不这样做的后果 / 依据 |
|---|---|---|
| TVS ≤5pF | 静电防护，容性不伤通带 | 普通 TVS 数十 pF → 500kHz 相位/增益漂移不可控 |
| 50Ω 端接 | 匹配题面 50Ω 电缆；电平与源阻抗无关；**×0.5 同时是链路里唯一免费且无失真的抗混叠增益**（折叠残留减半：2.62→1.31mVpk） | 不端接：残留翻倍 >1.5mV 峰门限，须抬门限、伪峰风险 |
| AC 耦合 1（100nF/10k，fc=159Hz） | 隔源端 DC 偏移，把单电源域入口偏到 1.65V | 直耦：输入 CM 摆到 −112mV 出轨（u_b+u_J 反相叠加最坏） |
| **BUF1（G=1）** | 高阻读端接节点（端接值精确）、低阻经 50Ω 串联电阻驱动 LC；G=1 输出摆幅最小 → 对未滤除的 u_J 处于最线性区 | v2 缺此级：LC 直接挂电缆/TVS 节点，端接与滤波器输入阻抗互相扰动 |
| 50Ω 串联 + LC + 50Ω 负载 | 双端接梯形：低元件灵敏度、无稳定性问题、@1.5M −43.7dB | 有源 8 阶：需 GBW≥205MHz 运放 + Q 稳定性风险 |
| AC 耦合 2 | 滤波器输出回到 0V DC（负载电阻接地），再抬到 1.65V 进增益级 | 单电源域必需 |
| **GAIN（×4）** | 滤波后才加增益 → 运放只见带内 ±62.5mVpk，u_J 已 −43.7dB → IM3 无从产生；同相输入高阻兼作滤波器的终接隔离（"后跟随"的职责由本级输入完成）；低阻输出经 100Ω 直驱 ADC（"后跟随"的驱动职责由本级输出完成） | 增益前置：u_J ±400mVpk@≥1MHz 打进运放，IM3 产物落带内且**滤波器无法去除**（失真产生在滤波器之前） |
| 100Ω+470pF | ADC 开关电容 kickback 隔离；Rsrc=100Ω ≤1.1kΩ（SMP=3 要求） | 无：采样电荷反冲在 ×4 输出产生建尖 |
| 不加第三管（输出跟随） | ×4 已是低阻驱动，再串 G=1 只多一级 droop 与失真源，零收益 | 主见：拒绝为"结构好看"加管 |

| 节点 | DC | 最坏交流 | 核算 |
|---|---|---|---|

## 4. fc=800kHz 的理论依据（反解，非沿用）

- 唯一硬频率：折叠带起点 **f_fold = fs − f_max = 1.5MHz**（≥1.5MHz 的干扰才折进分析带；[1.0,1.5)M 的镜像落 [0.5,1.0)M 带外；1.0M 整落 Nyquist bin 丢弃）。
- 残留约束：伪峰不过峰门限 → 100mVpk(u_J) × 0.5(端接) × |H(1.5M)| × 4(增益) ≤ 1.5mV
  → **|H(1.5M)| ≤ 0.0075 即 −42.5dB**。
- n 阶巴特沃斯解：[1+(1.5M/fc)^2n]^−½ ≥ 0.0075 → n=8 得 **fc ≤ 813.7kHz**；n=6 得 fc ≤ 663kHz。
- **fc=800k = 门限反解出的最大标准值**（留 0.9dB 余量）；此时通带 @500k 仅 −0.003dB（标称读数即准，利调试）。
  n=6/650k 省 2 个元件但通带 −0.18dB（标称口径失真，只能标定后读数）——为调试期可用性取 n=8。
- 上限验证（复算报告 §1）：−43.7dB@1.5M ✓ −15.6dB@1.0M（镜像带外）✓ −79dB@2.5M ✓。

## 5. 核心板（立创·天空星 F407VGT6 高配版）对本设计的事实

| 事实 | 对设计的影响 |
|---|---|
| **VREF+ 三路可选**（R1/R2/R4 贴法：板载基准 / 排针外部基准 / 主电源磁珠） | REF3033 走**排针外部基准**贴法注入——官方支持路径；具体电阻位/排针脚阶段二对原理图确认 |
| 板载 LDO SCJA1117B-3.3（钽电容）自供 MCU | 底板 AMS1117 只供 LCD 数字/触摸，不加载核心板 |
| 5V 排针/Type-C 共用过流保护+防反接+钳位(~13V) | 底板 5V 排针馈入即可，无需重复保护 |
| AGND–DGND 0Ω 单点在核心板 | 底板模拟地与核心板 AGND 的连接点阶段二定（经 0Ω/磁珠） |

### 6.2 量化后拒绝（防返工，数字在 `report_opt.md`）

| 候选 | 收益 | 拒绝理由 |
|---|---|---|
| fs 微调 K=71（2.0282M） | 残留 1.31→1.13mV | 收益 0.18mV，代价=软件文档全部 DSP 复算重跑回填；K=64~70 更优但 Δf>500Hz 违规 |
| 增益 ×4→×6 | 0.0004 mV | 量化噪声本就可忽略；白吃回归面 |
| 输入串 100Ω 加强保护 | — | 须改 100Ω 系统梯形，增益同步 ×8 → 残留反升 1.31→1.74mV；TVS+50Ω 端接已够 |
| 双帧变频识别 u_J | 残留→~0.1mV，余量→30× | 收益最大但回归面最大（§5/§6 重写+全重跑）；挂「精度拉满」可选项，余量 3.8× 下不做 |
| **内置 DAC 标定源**（DDS→模拟开关→AFE 输入） | 现场自标定不依赖外部信号源 | **不可行**：F407 DAC 建立 ~3µs（DS8626，复核✓），500kHz 正弦周期 2µs，模拟输出跟不上；寄存器可写 10.5MSPS（AN4566）但模拟域不建立=幅值未知，标定源必须幅值已知 → 毙。且生成器竞测必然在场（u_b+u_J 必用） |
| 双 ADC 交替采样提 fs | 翻案 fs=2.0M 冻结参数 | 拒 |
| 温漂对抗（TCXO/低温漂基准） | 判据无关（±20ppm=0.5Hz@25kHz vs 1kHz 判据） | 拒 |

### 6.3 Plan B 挂起（触发条件制）

- **椭圆（Cauer）n=6 滤波器**：零点@1.5M + Amin=50dB → 残留 0.63mV、余量 7.8×，且比巴特沃斯 n=8 少一个电感。
  不先做的理由：元件值非 E24、零点随容差漂移、DSP 文档滤波器模型要改。
  **触发条件**：板到手扫频标定后，混叠残留实测 > 预算，或竞测发现 u_J 相关伪峰 → 启用重设计。
