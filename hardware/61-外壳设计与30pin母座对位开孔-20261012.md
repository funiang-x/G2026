# 61 · 外壳设计与 30pin 母座对位开孔（2026-10-12）

> **用途**：**立创EDA 3D 外壳建模**的设计交付 —— 两件式外壳总体 + **全部开孔/槽位坐标**（含 30pin 母座对位区），可直接照表落图。
> **性质**：设计稿（几何已由脚本机器校核 15/15 通过）；**2 项参数待实测**（母座塑高、转接板厚），影响高度档位。
> **基准口径**：**板坐标**（原点 = 底板框 bbox 左下角；mm；X 右、Y 上；**Z=0 在底板顶面**，向上为正）。**第一基准 = 母座中心 (38.86, 82.85)**。
> **关联**：`60`（堆叠尺寸清单）· `58`（屏/转接板）· `tools/hardware/enclosure/build_case_v4.py`（参数化脚本，本设计给其定档）。
> **校核脚本**（可复跑）：`_work/mech_dim_20261012/enclosure_layout_check.py`

## §1 母座规格判断（30pin = 2×15 直插母座，本项目 J5）

| 项 | 判断值 | 依据 |
|---|---|---|
| 型号 | `2.54-2*15P母`（BOOMELE，LCSC C58377） | `hardware/data/bom_export_20261011.csv` |
| **引脚间距** | **行距 2.54 × 列距 2.54**；列跨 **35.56**（15 列） | 活体焊盘（`pcb_snapshot_20261011.json`：奇/偶排 Y 差 100 mil） |

| **塑高 H** | **8.5（标准款）/ 10.1（加高款）—— 两档，待实测定档** | BOOMELE 常规款；v4 脚本曾记 10.1 |
| 焊脚 | 0.64 方针，穿板后底面露出 ≈1.5（+焊锡） | 通用件 |
| **插拔方向** | **+Z 竖直**（转接板从上方插入）；无锁扣，拔出力沿 −Z | 装配形态（屏在上） |
| 中心位置 | **(38.86, 82.85)**（板坐标）；塑体 X∈[19.81, 57.91]、Y∈[80.25, 85.45] | 活体实测 |

**所需安装空间（三块）**：
1. **本体包络**：40.10 × 7.20 × 9.00（本体 + 单边 1.0 余量；H=8.5 档）；
2. **插拔通道净空**：以母座中心为轴、**56.01 × 98.71 的方柱**、Z 从 0 到 **+11.0**（8.5 档；10.1 档 +12.6）——**此方柱内禁止外壳任何结构侵入**；
3. **拔插路径**：通道上方全通（拆盖后可整块抽插屏模块）。

> ⚠️ 如果你的 30pin 母座不是这款：量出 **长/宽/高** 三个数，套用 §5 同一套公式即可（位置基准不变）。

**结构**：下壳（底 + 四侧壁 + 3 螺柱 + 脚垫凹槽，一体）+ 上盖（屏窗 + 定位框 + 唇边 + 3 螺孔）。

| 项 | 尺寸（mm） | 说明 |
|---|---|---|
| **外廓** | **86.05 × 117.70 × 37.26**（8.5 档） / **× 38.86**（10.1 档） | X×Y×Z（Z 从外壳外底起算） |
| 内腔 | 81.05 × 112.70 × 32.26（8.5 档） | 板周边单边间隙 0.4 |
| 壁厚 / 底厚 / 盖厚 | 2.5 / 2.5 / 2.5；竖边圆角 R4.0 | 沿用 v4 参数（可调） |
| 螺柱 | 3 × M3：**(4.32, 4.50)、(75.56, 4.50)、(75.56, 94.16)**；柱 Ø7.0、底孔 Ø2.6×深 7 | **SCREW3(40.64,46.53) 勿用**（在屏正下方） |
| 侧壁孔 | 左壁 **SMA Ø8.5**（中心 (0, 41.55)、Z = 板顶 +4.5）· 左壁 **Type-C 12×8**（Y=76.20、Z = 板顶 −10，**位置待实测**）· 右壁 3×4 × Ø2.4 散热孔 | 见 §3 表 |

**装配顺序**：拆上盖 → 屏模块（屏+转接板）插到 J5 上 → 整机放入下壳 → 合盖（定位框从上方套住转接板）→ 3 × M3 拧紧。

> **#3 / #4 就是"母座对应的区域"**：本设计把母座包在内腔里（不露壳），对插由"拆盖 → 插屏模块 → 合盖"完成。**#3 是保护性禁入区**（合盖后任何结构不得伸进该方柱）；**#4 是本体避让包络**（若你要在内腔加筋/垫块，必须让开这一区）。如果你的意图是"母座直接露在壳外"，那是另一种开壳方案，需另做（告知即可）。

## §4 对齐基准（为什么"不会错位"）

**基准链（一条直线推到底）**：

```
母座中心 (38.86, 82.85)             ← 第一基准（活体实测）
   │ 转接板 30pin 两排中点 = 母座中心（X 同轴；Y 两排中距北缘 4.4055）
   ▼
转接板北缘 y = 82.85 + 4.4055 = 87.2555
   ▼
转接板中心 y = 87.2555 − 98.71/2 = 37.90（x = 38.86，与 30pin 同轴）
   ▼
屏中心 / 屏窗中心 / 定位框中心 = (38.86, 37.90)   ← 与母座中心偏置 (0, −44.95)
```

- **X 向**：母座列跨 35.56 居中于 x=38.86 ⇒ 转接板 30pin 居中 ⇒ 转接板 x 居中 ⇒ 屏/窗/框全部同轴 38.86；
- **Y 向**：唯一偏置 **−44.95**（= 4.4055 + 98.71/2），本文档所有 Y 向坐标均由它派生；
- **落图时只需锁两个基准**：① 母座中心 (38.86, 82.85)；② 全部槽窗中心 = (38.86, 37.90)。

## §5 高度公式与两档参数（母座定档后一处改全表）

**层高公式**：`层高（板顶→转接板底）= H（母座塑高） + 2.5（排针塑胶）`
**框深公式**：`框深 ≥ 上盖内面 − 转接板顶面`（即"套入 0"的最小值；建议再加 0.5~1.5 套入量）

| Z 参考（8.5 档） | 值 | （10.1 档） | 值 |
|---|---|---|---|
| 板顶面 | 18.10 | 同 | 18.10 |
| 转接板底面 | 29.10 | 同 +1.6 | 30.70 |
| 转接板顶面 | 30.70 | 同 | 32.30 |
| 屏背面 | 32.20 | 同 | 33.80 |
| 屏面 | 34.26 | 同 | 35.86 |
| 上盖内面 | 34.76 | 同 | 36.36 |
| **外壳总高** | **37.26** | 同 | **38.86** |

> 实测得到 H 后：把上表 8.5 列的"转接板底及以下"全部 +Δ（Δ = H−8.5），框深保持 ≥4.1 即可。

## §6 公差与装配间隙（全部已核 ✓）

| 配合 | 名义间隙 | 备注 |
|---|---|---|
| 屏窗 − 玻璃 | 单边 **+0.50** | 屏外形 ±0.2 时最坏 0.30，仍 ≥0 |
| 压边（窗沿 → 屏模块沿） | 单边 **0.545** | 最坏 0.345；压边处贴 0.5 泡棉/双面胶 |
| 定位框内沿 − 转接板 | 单边 **0.50** | + 框口 0.5×45° 倒角；3D 打印公差 ±0.2~0.3 下最坏 0.2，仍可套入 |
| 转接板南缘 − 内腔南壁 | **0.50** | 转接板向 −Y 伸出底板部分 |
| 唇边底 − 转接板顶 | **2.06**（Z） | 唇边（环、宽 2.0 × 深 2.0）与屏/转接板均不碰 |
| 屏面 − 上盖内面 | **0.50**（Z） | 装配后垫泡棉 |
| 螺柱 − 转接板 / 屏 投影 | **不重叠**（3 处全过） | SCREW1/2/4 |
| 母座本体 − 内腔壁 | ≥ **8.7**（左右）、**17.9**（北） | 富余充足 |

> **3D 打印建议**：FDM ±0.2~0.3；母座/螺柱配合面预留 0.2 锉修余量；框口倒角必做。
