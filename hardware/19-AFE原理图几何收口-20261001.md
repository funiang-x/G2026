## 6. 2026-10-02 追加：DRC「网络图元不在原理图格点上($3N657)」收口

> 触发：UI DRC 面板报 `[警告] 网络图元不在原理图格点上。$3N657`（`sch drc` 只给计数、明说不等于 UI 全表，故此前未列明细）。

- **定位**：设计仅 3 页（INT/PWR/AFE）。AFE 页 **唯一一条自动命名网络**（挂 `C9.2 / R5.1 / U1.5`）几何未落 10 格 ⇒ 即被点名的 `$3N657`（自动名每次运行会变，如 API 侧读作 `$3N531`）。
- **实体根因**：`C9` 用 **30 间距符号**（居中 2100 → 两脚 2085/2115，必落半格 ✗），加该网一条 `(2360,1112)/(2300,1112)` 的 2 格拐点。
- **做法**：
  1. `C9` 中心 2100 → **2095**（两脚 2080/2110 全落格）；
  2. 该网所属三条折线（含 `C9.1` 侧链 `L7.2/TP3.1/C8.2/R4.1`、`U1.7` 侧链 `R6.1/R8.1`）**删除后按原拓扑重建为干净、无零长段、全落 10 格**的走线；重建前用并查集做**新旧连通划分等价证明**（三组：{C8.2,C9.1,L7.2,R4.1,TP3.1} / {C9.2,R5.1,U1.5} / {R6.1,R8.1,U1.7}，逐组相同）。
  3. 重建时按「**从被测引脚向外**」的顺序创建线段：EDA 合并折线会保留创建顺序，而 `pin-exit-direction` 规则看的是**合并后 segment 0** 是否离脚向外（U1.5 须朝左、U1.7 须朝右）；绕开 U1 体的走线取 `(2360,1050)→(2360,1100)→(2300,1100)→(2300,1130)`。
  4. 期间 `{x}` 单键 `modify` 把 `C9` 的 `otherProperty` **整表清空**（T-17/C5 复现）⇒ 按库记录 + 同页同类件模板回填：`Value=100nF / Tolerance=±5% / Voltage Rating=50V / Temperature Coefficient=C0G / Description=容值:100nF;精度:±5%;额定电压:50V;温度系数:C0G;`。
- **结果**：UI DRC **警告 3→2、信息 3→2** —— `网络图元不在格点上` 与 `C9 值为空` 均消除；余 2 条为既有「器件属性与供应商编号不匹配（建议器件标准化）」警告（**本机无 API**，需人工在 EDA 里处理）。`sch check` 保持 **1（仅 INFO）**、`sch clusters` 0 ERROR、`sch bridge-check` 0/0/50 树、`sch save` 已落。
