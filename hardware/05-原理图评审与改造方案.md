## §3 数值复算：A4 的量化（脚本 `_lc_recheck.py`）

8 阶巴特沃斯 · 双端接 50Ω · fc=800kHz · 级联 ABCD 求 |S21|：

| f | 设计值 (L=3.9/16/20/11) | 画布值 (L=3.9/**15/18/12**) | 差 |
|---|---|---|---|
| 100 kHz | −0.000 dB | −0.000 dB | — |
| 500 kHz | −0.011 dB | −0.007 dB | +0.004 |
| 800 kHz | −2.914 dB | −1.305 dB | +1.609 |
| 1.0 MHz | −15.054 dB | −12.927 dB | +2.127 |
| **1.5 MHz** | **−43.104 dB** | **−42.180 dB** | **+0.923** |
| 2.5 MHz | −78.817 dB | −78.129 dB | +0.688 |

**判据**（02 §4 反解）：折叠带起点 1.5MHz 需 **≤ −42.5 dB**。

- 设计值：−43.10 dB → **通过**，余量 +0.60 dB（注：`02 §4` 写 −43.7dB，口径略有差异，量级一致）。
- 画布值：−42.18 dB → **不通过**，**欠 0.32 dB**。

> ⚠️ 即使改回设计值，余量也只有 0.6 dB —— 与 `docs/02 §2` 已登记的 **HB2「混叠残留余量薄」** 一致。
> 这意味着 A4 修好只是"回到合规线"，不是"回到安全区"。是否顺手启用 **Plan B（Cauer n=6，Amin=50dB）**，见 §5 待拍板 T4。
>
> **口径备注（2026-09-28 补）**：项目日志（`.workbuddy-ai/memory/2026-09-28.md`）记录 SB4 已澄清——
> 0.655mV 与 1.309mV 是**不同参考点**（输入端 vs ADC 端，比值 = 4×0.5 = 2），
> 误差预算表与峰门限 1.5mV **都在输入端域**，故若按输入端域反解，门槛应为
> `100mVpk × |H| ≤ 1.5mV → −36.5dB`，而非 `02 §4` 写的 −42.5dB。
> 两个口径的差异不影响本节结论的**方向**（画布值最差、设计值勉强），
> 也不影响 §4 的改造定案：**fc=660kHz 方案在两种口径下都通过，余量分别为 16.8dB / 22.8dB**。

## §4 改造方案（目标态）

### 4.1 总原则

1. **图必须自证**：主信号链用**实线**画出来，端口只用于跨页与电源/地。
2. **一位一号**：所有器件标注位号，前缀按器件类型（U/R/C/L/D/Q/J/TP/JP/FPC/CN）。
3. **一名一网**：网络名以 `04-pinout连接表.md` 为准，图与表**逐条对账**。
4. **一页一职**：页名 = `AFE` / `PWR` / `INT`，页序 AFE→PWR→INT，工程名改 `G2026-底板`。
5. **改一个数，重跑一次**：任何 LC/增益/采样参数改动，先重跑 `verify_afe_v2.py` 与 `tools/verify_dsp.py` 再落图。

### 4.2 AFE 页（重画）

- **信号链实线**：`J1(BNC) —D1(TVS)— R1(49.9Ω) —C1(100nF)— U1A(BUF1, G=1) —R2(49.9Ω)— [LC8] —C6(100nF)— U1B(GAIN ×4) —R? (100Ω)+C?(470pF)— JP2 — AFE_ADC_IN`，一条线走到底。
- **LC8 用子框圈起**，标注"8阶巴特沃斯 fc=800k 双端接50Ω"，元件值标设计值。
- **电源/地走旗标**：`+5V_A` / `AGND`；**跨页走端口**：`AFE_ADC_IN` / `VBIAS_1V65` / `VREF_3V3_EXT`。
- **功能分区**（虚线框 + 文字标题）：①输入保护与端接 ②缓冲 ③抗混叠滤波 ④增益与 ADC 驱动 ⑤基准与偏置 ⑥测试点与断点。
- **补**：U1 的 V+/V− 就近 100nF 去耦；REF3033 输出改陶瓷电容（10µF 0805 X7R + 100nF C0G，或按 datasheet）。

### 4.3 PWR 页（重画）

- 5V 入口：`DC005 → SS34 → PPTC → +5V_MAIN`（按 04 电源树统一命名）。
- 数字 3.3V：`AMS1117-3.3`（SOT-223）+ 22µF 钽输入 + 22µF 钽/10µF 陶瓷输出 + 100nF。
- 背光：`+5V_MAIN → R_bl(**39Ω 0.5W**) → LED_A`；`LED_K → Q1(SI2302) → GND`；`PB0 → 1kΩ → Q1_G`；`100kΩ` 栅极下拉；**恒亮禁 PWM**（注释写死）。
- IM 绑定：`IM0=GND / IM1=3V3 / IM2=GND`（8080-16bit），加醒目注释"**不得照抄厂家 SPI 转接板**"。
- I²C 上拉 4.7k×2；LCD_ID 100k→GND。
- **补**：FSMC D0~D15/NE1/RS 的 33Ω 串阻（放在 PWR 或 INT 页，二选一，不重复）。

### 4.4 INT 页（修补为主，尽量保留现有走线）

- **替换 EVK1 符号为 STM32F407VGT6 高配版**（A1）→ 逐脚重核 `04 §1.1` 的映射。
- 屏 FPC-45P（H3）逐脚按 `04 §1.2` 表核对；触摸 FPC-6P（H4）按 `04 §1.3`（脚序仍为 [TBD]，图上加醒目注释）。
- 板间互连连接器针数按拍板结果（T3）统一。
- 处理悬空的 3 个 `={Manufacturer Part}` 标签。

### 4.5 三页共做

- 标题栏：工程名 / 版本 / 日期 / 页号 / 设计者。
- 网络名全项目唯一化 + 与 04 表对账脚本（`_netcheck.py`）。
- 出 BOM 并与 03 选型表逐条比对（脚本 `_bomcheck.py`）。
