> **性质**：只读实测 + 计算（**未改动你的工程任何对象**）。数值全部可由 `_work/mech_dim_20261012/` 脚本复算。
> **前提（重要）**：立创EDA **公开 API 不能写外壳层**（详见 §6），所以本清单是"**给你在 EDA 里照改的精确数值**"，不是自动写入。

## §1 分析怎么做的（可复算）

**读法**：经 API Gateway（`bridge-server.mjs`，端口 49620）调 `eda.pcb_ManufactureData.get3DShellFile('…','obj')`
→ 得到 zip，内含 `3DShell_p_T.obj`（上壳）/ `3DShell_p_B.obj`（下壳）→ 分块取回本地 → 解析。

**坐标映射（三条 M3 孔位拟合，残差 ≈ 0.2 mm）**：

```
板 x = 导出X − 43.62
板 y = 193.17 − 导出Z        ← 导出坐标在 Z 轴上与板坐标反向
板 Z(高度) = 导出Y − 20.0    ← 见 §1.1 基准推导
```

**拟合依据**（你外壳上 3 个 Ø4/Ø6.5 孔 ↔ 底板可用 M3 孔）：

| 你的孔（导出） | → 板坐标 | 底板孔位 | 差 |
|---|---|---|---|
| (47.81, 188.59) | (4.19, 4.58) | SCREW1 (4.32, 4.50) | 0.15 |
| (119.31, 188.59) | (75.69, 4.58) | SCREW2 (75.56, 4.50) | 0.16 |
| (119.31, 99.09) | (75.69, 94.08) | SCREW4 (75.56, 94.16) | 0.16 |

> ✅ 且第 4 角 (4.32, 94.16) **你和我都没做孔**——与底板"只有 3 个可用 M3 孔"完全一致，反证映射正确。

### 1.1 高度基准（自洽性验证）

用"**上下壳分界面 = 板顶面**"（导出 Y = 20）代入既有设计链：

```
板顶(0) + 11.0(母座对插层高) + 1.6(转接板) + 1.5(FPC) + 2.06(屏) = +16.16
20.0 + 16.16 = 36.16  ≈  你外壳实测总高 36.00     （偏差 0.16 → 自洽 ✓）
```

对照：若按"SMA 在板顶+4.5"反推板顶（导出 Y=11），则总高只有 ~27 ✗ 不成立。
⇒ **采用 板顶 = 导出 Y 20**，本文全部高度按此换算。

## §4 三个必须处理的风险

1. **内腔比底板窄 1.25 mm** —— 内腔实测 **79.0 × 127.0**，而底板 bbox **80.25 × 100.25** ⇒ **板放不进去**。
   处置：内腔 X 向至少 **+1.5**（左右各留 0.4~0.5 间隙）⇒ 内腔 ≥ 81.05（或把壁厚由 3.0 减到 2.5 并外廓加宽）。
2. **屏窗过大**（56.0 > 屏模块 55.05）⇒ 屏无压边、无法定位/固定。按 §3.1 建议值改。
3. **下壳未检出螺柱/支撑** —— 若外壳要承板，需补 3 处支撑（对应 SCREW1/2/4），柱位与上壳 3 个 Ø4 孔**同心**：
   | 位号 | 板坐标 | 上壳孔（导出） |
   |---|---|---|
   | SCREW1 | (4.32, 4.50) | (47.81, 188.59) |
   | SCREW2 | (75.56, 4.50) | (119.31, 188.59) |
   | SCREW4 | (75.56, 94.16) | (119.31, 99.09) |

## §5 在立创EDA 里怎么填（对照表）

**坐标口径**：下面给 **板坐标**（底板框左下角为原点，mm，X 右 Y 上）；若你的外壳编辑器用"外壳自身坐标"，改用括号内的**相对外壳值**。

| 开孔 | 填什么 | 基准 |
|---|---|---|
| 屏幕开窗 | 中心 X **38.86**（= 距左外壁 42.00）、Y **37.90**（= 距外壳南端 58.50）；尺寸 **53.96 × 82.34** | 与母座 J5 同心 |
| SMA 孔 | 板 y **41.55**；高度 **板顶面 +4.5**（= 外壳外底上方 **24.5**）；Ø **8.5** 通孔 | J1 中心 |
| USB 孔 | 板 y **以实物核**（v4 参考 76.20）；高度 **板顶面 −12.5 ~ −14.0**（= 外壳外底上方 **6.0 ~ 7.5**）；开口 **12 × 6 ~ 8** | Type-C 座位置 |

**自检三问**（改完在 EDA 里量一遍）：
1. 屏窗两条边是否都**小于**屏模块 55.05 × 84.50？（压边 ≥0.3/边）
2. 内腔宽是否 **> 80.25 + 0.8**？
3. SMA 孔中心是否**高于板顶面**（在外壳外底上方 24.5 附近）？

## §6 能力边界（为什么不能替你写）

立创EDA 的 `SHELL_3D_OUTLINE/TOP/BOTTOM`（层 53/54/55）**只在"可选层"清单**里；官方图元类型 `TPCB_LayersOfFill / OfLine / OfRegion / OfObject` **均不含外壳层**，对外壳**只有导出（`get3DShellFile`）与下单（`place3DShellOrder`）两个接口**。
⇒ 外壳几何写入 = **unsupported**；本清单给的是**精确数值**，落图需你在 EDA 界面完成（`easyeda-agent` 硬红线亦禁止 GUI 自动化代改）。
