- **分类**：模拟链 / 数字与时钟 / 显示与触摸 / 电源与热 / 信号完整性 / 地与 EMC /
  机械与装配 / 供应链与器件 / 固件与软件 / 测试与评审 / 过程。
- **五要素**：现象 · 根因 · 影响（对**题面判据**还是对**可靠性**）· 概率 · 检测与缓解。
- **状态词**：`已闭`（有证据）/ `已缓解`（有措施，待实测确认）/ `待实测` / `待人工` / `已接受`。

  u_J **200mVpp @≥1MHz** · 单 5V 供电 · 屏 ≥6″ · 板上 BNC 座。
