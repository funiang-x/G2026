## §1 前提与口径

| 项 | 值 | 依据 |
|---|---|---|
| 层数 | **2 层**，1 oz（35 µm） | `16 §4-1` |
| 参考平面 | **无**（这是全部难点的根源） | 同上 |
| 焊接 | 手焊 ⇒ 禁 QFN/BGA | `01` 约束 10 |
| 核心板 | 立创·天空星 F407VGT6-PRO（双排针 P1/P2 引出） | `04 §6.12` |
| 屏接口 | `J5` = 2×15 2.54mm **通孔直插**母座（C58377） | `13 §5.6` |

**线宽不是载流问题，是阻抗/压降问题** —— 先把这条说清，免得过度加宽：

- 1 oz、0.25mm 宽、10 °C 温升下约 **0.87 A**；0.5mm 约 **1.4 A**（IPC-2221）。
  而本板最大电流是 `+3V3` 的 ~90mA、`+5V` 的 ~0.1A ⇒ **载流有 >10× 余量**。
- 但**电阻**要算：1 oz 下 0.5mm 宽约 **1 mΩ/mm**，0.25mm 约 2 mΩ/mm。
  - `+5V`→核心板 50mm 走 0.5mm ⇒ 50 mΩ × 0.1A = **5 mV** ✓ 可忽略。
  - **背光支路是例外**：3V3 与 `Vf` 的余量只有 **~0.2 V**（`36 §M.2`），
    所以 3V3 与它的 GND 回流**每一段都要宽、要短** —— 若整段有 0.5Ω，@60mA 就是 30mV，
    **等于吃掉 15% 的余量**，电流跟着漂。

**建议线宽**：电源/背光 **≥0.5mm** · 一般信号 **0.25mm** · 总线束 **0.25~0.3mm** · 地**铺铜 + 多缝合过孔**。

## §2 总纲：分区与地

### 2.1 分区（把板子当三块 + 一个电源区）

```
┌─────────────────────────────────────────────────────────────┐
│  板边                                                       │
│  ┌──────────────┐   ┌─────────────────────────────┐         │
│  │ ① 电源区      │   │ ③ 转接区                     │         │
│  │ C16/R21/C11   │   │  EVK1 核心板座 + J5 30-pin   │         │
│  │ C14（无入口件）│   │  R22~R42 串阻阵列 + C21/C22   │         │
│  └──────┬───────┘   │  R15/R16 + R12               │         │
│         │ +5V_A     └─────────────────────────────┘         │
│  ┌──────▼───────────────────┐        ↕ ≥10mm 隔离带          │
│  │ ② AFE 区（AGND 独立岛）   │                               │
│  │  J1 SMA → R1/D1/C1 → U1A │                               │
│  │  → R3/L1..L7/C2..C8/R4/C23│                              │
│  │  → C9 → U1B → R8/C10/JP2 │                               │
│  │  R9/R10/C13 (VBIAS)      │                               │
│  │  TP1~TP5 · C11/C14       │                               │
│  └──────────────────────────┘                               │
└─────────────────────────────────────────────────────────────┘
```

**布局顺序**：先钉 `EVK1` 与 `J5` 的座子位置（它们决定一切），再排 AFE 的一字长蛇，
最后补电源区。**AFE 的一字顺序不许绕回**：

```
J1 → R1 → D1 → C1 → JP1 → U1A → R3 → L1 → C2 → L3 → C4 → L5 → C6 → L7 → C8
   →(R4+C23 入 AGND)→ C9 → U1B → R8 → C10 → JP2 → 【AFE_ADC_IN】→ PA1
```

> 理由：输入节点（`L1` 前）与输出节点（`C8` 处）之间如果绕回来，就形成耦合路径；
> 这条链的阻带衰减靠的是**每节都在正确的位置**，不是靠元件本身。

### 2.2 地：`AGND` 是**独立岛**，唯一回路在核心板

**这是本板最容易做错的一件事，也是唯一"做错了不报错"的一件事。**

| 层次 | 是什么 | 怎么做 |
|---|---|---|
| ① 电气单点在哪 | `AGND` 与 `GND` 只在一个点相连 —— **那个点是核心板的 `R8`（0Ω，已实测贴）** | **底板不连**。这不是"取消单点接地"，是**这个点已由核心板提供，你不能再造第二个** |
| ② 底板 `AGND` 铜皮怎么汇 | AFE 页 **18 个**模拟地成员 | **只汇到 `EVK1.37` 一个点**，无第二条出路 |
| ③ 回流不许借道 | 数字回流（FSMC 束 / 背光） | **不得跨越 `AGND` 岛**（≥10mm），底层铺铜也不许把两者连起来 |

```
        ┌── AGND 铜皮（只在 AFE 区内，独立成岛）──┐
        │  J1屏蔽脚 R1 R4 R7 R10 C2 C4 C6 C8      │
        │  C10 C11 C13 C23 C14 U1.4 D1.2           │
        └────────────────┬────────────────────────┘
                         │  ← 唯一出口，只有这一条
                    EVK1.37 (AGND 针)
                         │
                  ┌──────┴──────┐  核心板内部
                  │  R8 (0Ω,贴) │
                  └──────┬──────┘
                         │
        ┌────────────────┴────────────────────────┐
        │  GND 铜皮（整片铺，含数字区）             │
        │  --(J3已删)  EVK1.39/77/79 J5.29 C16 C21 C22 │
        └─────────────────────────────────────────┘
```

**判据（可勾）**：
- 底板网表里 `AGND` 与 `GND` **零连接件**（原理图这一层已经是对的，"单点"是靠**不连**表达的）；
- 目视：两块铜皮不重叠、无 0Ω/跳线/过孔桥接；
- `AGND` 的每个成员都能追到 `EVK1.37`，且**只有一条路**。

### 2.3 缝合过孔：2 层板唯一的"降低共地阻抗"手段

没有参考平面时，回流只能靠**走线和铜皮**。两条实用结论：

- **过孔并联**：`N` 个过孔并联，等效电感降到约 `1/N`（互感会让实际略高于 `1/N`，量级成立）。
  ⇒ `J5` 的 GND 脚周围打 **≥6 个**过孔到铺铜，是**最便宜的一招**。
- **回路长度**：`L_gnd ≤30nH` 这个目标，在 2 层无平面下**基本就是"把 GND 回路压到 cm 级"**。
  ⇒ `J5.29` 到铺铜、`EVK1` 的地针到铺铜，都走**短 + 宽 + 多过孔**。

### 3.2 逐项布局判据

| # | 针对 | 判据 | 为什么 |
|---|---|---|---|
| A1 | `J1` + `R1` | `R1` 距 SMA 中心针 **≤2~3mm**；`J1` 靠板边，焊盘加宽 + 多打过孔 | `13 §5.7`：中间那段走线就是电感；插拔力矩全压在 SMD 焊盘 |
| A2 | `R1` 的地 | `R1` 的接地端**直接下到 `AGND` 岛**，不和别的信号共用地线 | 它是 50Ω 端接，任何共地阻抗都会改变端接值 ⇒ 幅度随信号源变 |
| A3 | `D1` | 放在 `R1` 之后、`C1` 之前（**在输入端**），地回 `AGND` | TVS 要在最靠外的地方钳位；放里面就白装 |
| A4 | `C1` | 1206 C0G，信号路径**直线**通过，两侧不留长桩线 | 它是隔直电容，串在信号路上，桩线 = 额外电感 |
| A5 | `U1A`/`U1B` | 两半片在**同一颗 SOIC-8** 里，但 `U1A`（输入侧）与 `U1B`（输出侧）在链的两端 ⇒ **`U1` 的摆放位置决定整条链能不能一字排开** | 先定 `U1` 位置，再往两边排 |
| A6 | `C11`(22µF) + `C14`(100nF) | **紧贴 `U1.8(V+)`**，两条并联、地回路**同一个点**回 `AGND`，环路面积最小 | 去耦的作用靠"环路电感"决定；一大一小并联是因为大电容对高频不灵、小电容对低频不灵 |
| A7 | `R9`/`R10`/`C13` | 三个凑在一起；`C13`(10µF) 紧贴分压点；`C13` 的地回 `AGND` | `C13` 的地端**2026-10-02 才从 `GND` 改成 `AGND`** —— 它是 AFE 页唯一曾落错地的点，别改回去 |
| A8 | `VBIAS` 走线 | **短、不与数字线平行**；`C13` 放在分压点与 `U1B` 之间 | `VBIAS` 源阻抗是 `10k∥10k = 5k` 的**高阻节点**；而 `R7` 是 `U1B` 的**反馈网络**一部分 ⇒ `VBIAS` 上的任何串扰**直接进闭环** |
| A9 | `R6`/`R7` | 紧贴 `U1B` 的 `-in` 与输出，反馈回路面积最小 | 反馈走线越长，寄生电容越容易让通带形状变（`27 §S1` 就是这条的量化） |
| A10 | `TP1`~`TP5` | 每个都**留出探针可达空间**（别被高件挡住） | 没有它们，`27 §8.7` 的扫频标定一个点都做不了 |
| A11 | `C9`/`R5` | 紧贴 `U1B` 的 `+in` | 与 `A8` 同理，不过这里是信号侧 |

### 3.3 本块**最难的一处**：`C10` 的两难与取舍

`C10`(470pF) 是 ADC 的"小水缸"——采样瞬间 ADC 从它抽电荷，它把那一口补上。
它同时被两条要求拉扯：

| 要求 | 指向 | 冲突点 |
|---|---|---|
| ① 靠近 **PA1**（`EVK1.4`） | 采样反冲要近 | PA1 在**数字区**（核心板插座那一侧） |
| ② 回流到 **`AGND` 岛** | 它是模拟采样网络的一部分 | `AGND` 岛在 AFE 区，与数字区隔 ≥10mm |

**两条不能同时最优。取舍判据**（本轮推导）：

- `R8`+`C10` 的放电时间常数是 **τ = 47 ns**（`26 §2.5`），对应带宽 ~3.4 MHz；
  而 `AFE_ADC_IN` 这一段走线的寄生是 **nH/mm 量级** ⇒ 在 3.4 MHz 上，**走线长度的影响远小于
  把数字回流引进 `AGND` 岛的代价**。
- ⇒ **结论：`C10` 留在 `AGND` 岛内，放在岛最靠近 PA1 的那一角**；
  让 `AFE_ADC_IN` **独自从那个角走到 PA1**，且这条线**独占、不与其他信号并行、两侧用地铜皮包夹（guard）**。
- 这条线是**全板唯一的模拟→数字跨域点**（`26 §5`），值得单独对待。

**同理**：`JP2`（0Ω 断点）放在 AFE 区边缘，方便断开单测；`TP4` 放在 `JP2` 之前且探针可达。

### 3.4 稳定性（自激）：风险在**高阻节点**，不在输出节点

> 完整分析见 `36 §M.6`（脚本 `tools/sim/stability_check.py`）。这里只放**布局判据**。

先说结论：**拓扑上不会自激**，靠的是三道保护 ——
① `U1A` 反馈点在**输出引脚**、`R3` 在**之后** ⇒ 梯形大电容在环外；
② `U1B` 同理，`R8` 在反馈点之后 ⇒ `C10` 在环外；
③ `U1B` 噪声增益 **7.975**（不是 1）。

**但有一个反直觉的量化结论**（本轮算出来的）：

| 节点 | 该节点的阻抗 | 寄生电容 | 形成的极点 | 在 1.25MHz 环穿越处的相位损失 |
|---|---|---|---|---|
| **`U1B` 的 `−in`（`FB`）** | **`R6∥R7` = 3.12kΩ`（高阻！）** | 运放 `Cin` **12 pF** | **4.25 MHz** | **16.4°** |
| 同上，+ 板级杂散 **5 pF** | 3.12kΩ | 17 pF | 3.00 MHz | **22.6°** |
| 同上，+ 板级杂散 **10 pF** | 3.12kΩ | 22 pF | 2.32 MHz | **28.3°** |
| `U1B` 输出脚（`GOUT`） | `Ro` ≈ **100Ω`（低阻）** | 100 pF | 16 MHz | 仅 **4.5°** |

⇒ **要命的节点是 `−in`，不是输出。** 因为它的阻抗比输出高 **31 倍**，同样的寄生电容造成的极点低 4 倍。

**布局判据（新增，硬约束）**：

| # | 判据 | 为什么 |
|---|---|---|
| A12 | **`R6`/`R7` 必须紧贴 `U1B` 的 `−in` 引脚**，`−in` 节点的铜箔/走线**越短越好**（目标 ≤3mm） | `−in` 是 3.12kΩ 的高阻节点 ⇒ **每多 5pF（≈5mm 走线量级）就多吃约 6° 相位裕度** |
| A13 | **`−in` 节点下方不走数字线、不与其他信号并行**，该节点附近**不要铺大面积铜** | 同上；这是唯一一个"布局直接吃掉稳定裕度"的地方 |
| A14 | `R6`/`R7` 用 **0805 短体**（不要用长体/多个串联凑值） | 减少节点面积 = 减少杂散电容 |
| A15 | `C11`/`C14` 紧贴 `U1.8`（见 A6） | 去耦失效是自激的经典诱因；`23 §7 V5` 已用 `+5V_A` 压降当"是否振荡"的探针 |

> ⚠️ **另一条硬约束（与 `23 §1` 呼应）**：**`R6`/`R7` 必须是 24.9kΩ / 3.57kΩ，不能换回 69.8k/10k。**
> 旧取值把 `R6∥R7` 从 3.12kΩ 抬到 **8.75kΩ** ⇒ 同一个 `−in` 极点从 4.25MHz 掉到 **1.52MHz**
> ⇒ 穿越处相位损失从 **16.4° 涨到 39.6°**（最坏 `Cin` 下 **58.8°**）。
> **通带形状不对还能标定，自激不能标定** —— 这是"必须贴 24.9k/3.57k"的**第二条、更硬的理由**。

## §4 块② 滤波（8 阶无源 LC 梯形）

### 4.1 包含谁 + 顺序不能变

`R3` · `L1` `L3` `L5` `L7` · `C2` `C4` `C6` `C8` · `R4` · `C23` · `TP3`

```
U1A 出 → R3 → L1 →[C2↓AGND]→ L3 →[C4↓AGND]→ L5 →[C6↓AGND]→ L7 →●→ C9
                                                              ├─[C8↓AGND]
                                                              └─ C23 → R4 → AGND
```

**注意两个容易画错的拓扑事实**：
1. **`C8` 与 `R4` 是同一个节点**（梯形的负载端），`C23` **串在 `R4` 入地的那条腿上**，不是并在 `C8` 上；
2. **`R3` 既是"缓冲器与大容性负载之间的隔离"，也是梯形源端阻抗**（`30 §5.3` 已记）——
   **它不是"随便一个串阻"**，改它等于改滤波器。

### 4.2 电感：互感是这一块的头号敌人

| # | 判据 | 为什么 |
|---|---|---|
| B1 | **四个电感正交摆放**（相邻两颗的长轴互相垂直），间距 **≥2mm** | `L3`/`L5` 同为 22µH（同料 `CD54-220M`）⇒ 互感最大；`29 A4` 把它列为已缓解项，靠的就是这一条 |
| B2 | 电感**下方与邻近层不走高速线** | FSMC 的边沿会通过容性/感性耦合进梯子 |
| B3 | 电感**不要紧贴 SMA 金属壳体与其他大块金属** | 屏蔽式电感的磁路也会被靠近的金属影响 |

### 4.3 四个并联电容的地回路：要"收"不要"散"

`C2`/`C4`/`C6`/`C8` 是梯形的四个并联支路，它们的**电流全部回 `AGND`**。判据：

- 每个电容的**地过孔紧贴焊盘**（≤1mm），不要拉一段线再过孔；
- 四颗的接地点**朝 `AGND` 岛的同一条铜皮收拢**，不要散在四个角落 ——
  散开之后它们之间隔着铜皮的共地阻抗，等于在梯子里**偷偷加了耦合元件**；
- `C8` 与 `R4`/`C23` 是同一个负载端节点，**它们的地要汇在同一处**（这是最该合并的一对）。

### 4.4 `C23` 的位置（易错）

`C23`(10µF) 是"断掉梯内直流"的隔直电容 —— 没有它，电感上会白流 **16.4 mA** 直流
（`25 §1.3`，改前实测值）。判据：

- 必须落在 **`R4` 与 `AGND` 之间**（`R4` 的入地腿上），**不是并在 `C8` 两端**；
- `C23` 与 `R4` 紧邻，`R4` 另一端直接下 `AGND`。

### 4.5 测试点

`TP3` 是**滤波器输出**——`27 §8.7` 的扫频标定里最关键的一个点。
留出探针空间；`TP1`（端接点）同理。

## §5 块③ 转接板（核心板 ↔ 屏幕）

### 5.1 包含谁

| 子块 | 位号 |
|---|---|
| 核心板座 | `EVK1`（双排针 P1/P2） |
| 屏接口 | `J5`（2×15 通孔母座，30-pin） |
| 源端阻尼 | **`R22`~`R42`（21 只 33Ω）** |
| `J5` 就近去耦 | `C21`(10µF) · `C22`(100nF) |

### 5.2 `R22`~`R42`：**必须贴 MCU 侧**（这是全板最重要的一条布局约束）

这是**本轮用仿真量化过**的一条（`36 §F`，分布 LC 阶梯 + 5 ns 斜坡边沿）：

| 形态 | 不串 | **MCU 侧 33Ω** | **连接器侧 33Ω** |
|---|---|---|---|
| 成品（直插转接板，L≈60nH） | 8.8% | **4.9%** | 6.7% |
| 台面（100mm 杜邦，L≈215nH） | 46.6% | **22.5%** | **37.6%** |

- **处方**：贴 MCU 引脚 **3~5mm** 以内（越近越好）。
- **量化**：贴错侧只能拿到源端约 **1/3~1/2** 的降幅（台面 22.5% vs 37.6%，差 **1.67×**）。
- ⚠️ **注意纠正**：`18 §R-21`/`22 §5` 原话是"放连接器侧 **= 等于没加**"——
  实测不是"等于没加"，但**过不了"J5 侧过冲 <20%"这条判据**（连接器侧 37.6%）。结论不变：**必须贴 MCU 侧**。
- 图纸上它们画在 `J5` 侧是 **EDA 工具限制**（`18 §R-21` 的符号几何守卫），**不是设计意图**。
  ⇒ 画 PCB 的人只看图纸会画错，**所以这一条已经写进图上注释**（见 §8）。

### 5.3 总线束

| # | 判据 | 为什么 |
|---|---|---|
| C1 | 21 根（`D0~D15` + `CS/RS/WR/RD/RST`）**走成一束**；目标 **≤40mm**、硬上限 **60mm** | 2 层下回流路径连续性是唯一可靠的"地" |
| C2 | 束内**每 2~3 根插一根地**，或用地铜皮包夹 | 减小束内串扰；`CS`/`WR` 一被干扰就是**整屏级**后果（`22 §1` 的机理） |
| C3 | **不得跨地平面分割**；**不得穿越 AFE 区** | 跨分割 = 回流被迫绕远 ⇒ 环路面积暴增 |
| C4 | `J5` **尽量靠近** `EVK1` 的 FSMC 引脚那一侧 | 总线长度直接决定 C1 |
| C5 | `R22`~`R42` 的**两侧**：MCU 侧走线 ≤3~5mm，J5 侧走线随便 | 阻尼电阻的"分工"就是这样的 |

### 5.4 `J5` 的地 —— **全板最弱的一环**

`J5` 只有 **1 根地针（pin 29）**，却要承担 **21 条线**的回流（`28 §3.3`）。

| # | 判据 | 为什么 |
|---|---|---|
| D1 | `J5.29` **短、宽（≥0.5mm，最好直接铺铜连）**、周围**多打过孔（≥6 个）**到铺铜 | 地弹 ∝ `L_gnd × N × di/dt`，只有"并联"能压 |
| D2 | 目标 **`L_gnd ≤30nH`** | `29 §13 PCB-2` |
| D3 | `J5` 的位置让 `J5.29` **离核心板的地针尽量近** | 缩短回流总长度 |
| D4 | 若空间允许，把 `J5` 附近的**未用区域整片铺铜并缝到 GND** | 2 层没有平面，只能人工造"局部平面" |

### 5.5 `J5` 就近去耦

| # | 判据 | 为什么 |
|---|---|---|
| E1 | `C21`(10µF) + `C22`(100nF) **紧贴 `J5.30`，≤5mm** | `22 §3.1`：原图确实缺，是"间歇/位置相关花屏"的另一大成因 |
| E2 | **先 100nF（靠引脚）后 10µF** | 小电容管高频、要更近；大电容管低频、可远一点 |
| E3 | 两电容的地**同一个过孔点**回 GND | 否则两个回路面积叠加 |

### 5.6 触摸 I²C

| # | 判据 | 为什么 |
|---|---|---|
| F1 | `R15`/`R16`(4.7k) **就近主端 ≤10mm**（即靠 `EVK1`/`J5` 的上拉端） | 上拉位置决定边沿与抗扰 |
| F2 | `TP_SCL`/`TP_SDA` **不与总线束平行** | I²C 是慢速高阻线，最怕并行走线 |
| F3 | `TP_INT`（`PC5`）走线短；固件已配**输入+内部上拉** | 与触摸 IC 的开漏 INT 配合，别再加外部上拉对打 |

### 5.7 背光

| # | 判据 | 为什么 |
|---|---|---|
| G1 | 背光 3V3 与其 GND 回流**都走 ≥0.5mm、尽量短** | 3V3 与 `Vf` 的余量只有 ~0.2V，走线电阻**直接吃掉 LED 余量**（`36 §M.2`） |
| G2 | 背光回路与总线**不平行（≥10mm）**或用地面隔开 | 60mA 开关电流是大环路干扰源（`22 §5`） |
| G3 | `R12`(1k) 靠 `J5.28`，作栅极阻尼 | 背光只在开机翻一次，但走线远端会振铃 |
| G4 | ⚠️ **若实测背光电流超标，改从 `+5V` 串 33Ω/1206 喂**（`36 §M.2`）—— 那时要预留**一根从 +5V 到适配板的飞线**的位置与固定点 | `+5V` **不在 30-pin 接口上**，这一步必然要飞线 |

### 5.8 屏模组与结构

| # | 判据 | 为什么 |
|---|---|---|
| H1 | 屏模组**刚性固定**（直插转接板 / 排母），**禁杜邦飞线** | 飞线 = 振铃 + 接触不良（`23 PCB-6`） |

## §9 诚实边界

1. **本文是"设计要求"，不是"布局结果"** —— PCB 由人工完成（`WORKFLOW` ④），
   本文只把"必须守住什么"变成可勾的判据。
2. **`§0-3`/`§5.2` 的量化来自仿真**（`36 §F`），不是实测：
   分布 LC 阶梯的模型是 **Z0=120Ω / 驱动 30Ω / 5 ns 斜坡 / 末端 10 pF / 8 段**。
   **排序（源端优于负载端）稳健；绝对值不稳健** —— 上板仍须按 `23 §7 V12` 用示波器看 J5 侧过冲。
3. **`§2.3` 的"过孔并联降到 1/N"是量级结论**（互感会让实际略高）；`L_gnd ≤30nH` 这个目标来自 `29 §13`，
   本板**没有实测手段**在上板前验证它 —— 只能在 `V12` 里用"J5 侧过冲"间接判。
4. **背光那一条（`§5.7 G4`）依赖还没测的数**：模组 `Vf` 未知（`36 §M.2`），
   所以"要不要改从 5V 喂"**在测出电流之前不该动手**。
5. **本文不含**：机械结构（板框 / 安装孔，`29 G3` 仍是待定）、丝印规范、拼板与工艺边、阻抗控制
   （本板无 50Ω 受控阻抗要求 —— 唯一的 50Ω 段在 AFE 输入，靠 `R1` 的物理位置解决）。
