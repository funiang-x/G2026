### 5.2.1 补一轮：**旗标残骸清理**（2026-09-29 20:09，用户目视发现）

**症状**：用户指出 PWR 页 ④ 区里有几个"秃的 GND 旗标"（`x = 1680 / 1790 / 1900`，即已删的 `R17/R18/R19` 原位）。

**根因（我的工具 bug，两处）**：
1. **自环判定**：连通性洪泛时把**导线自己的端点**也并进了"锚点集合"，于是每条导线都"碰到自己" → **永远判 0 条死线**。
2. **浮点比对**：引脚坐标返回 `979.9999999999998`，而导线端点是 `980`，集合相等判定失败 → 即使不修 #1 也会漏判。

**修法**：改为**从器件引脚出发做"导线级 BFS"**（seed = 有端点落在引脚上的导线；反复并入与之共点的导线），坐标一律 `round()` 归一。
工具：`easyeda-sch-audit-fix/scripts/dangling.py`（可重复运行，幂等）。

**清除结果（16 项）**：

| 页 | 死线 | 残骸旗标 |
|---|---|---|
| **INT** | 2（H3 删除后残留的 GND 母线树、+3V3 母线树） | `+3V3@(660,1160)` `GND@(660,1300)` |
| **PWR** | 5（`R13/R17/R18/R19/R20` 原位的短线） | `GND@(1230,910)` `GND@(1680,960)` `GND@(1790,960)` **`+3V3@(1900,960)`** `GND@(2010,960)` |
| **AFE** | 1（`AGND` 残线） | `AGND@(2300,1000)` |

复扫：三页 **死线 0 / 残骸 0**；DRC 仍 **致命 0 / 错误 0**。
> **教训**：DRC **不会**报这类残骸 —— 因为旗标挂的是 `GND`/`+3V3` 这类**已存在的网名**，
> 导线不是"游离网络"。**"几何连通性自检"必须自己做，且判据里绝不能把导线自身当锚点。**

> ⚠️ **踩坑记账（已回写 skill 台账口径）**：`setDocumentSource` 追加记录时，**记录之间用 `|` + `\n` 分隔，最后一条末尾不带 `|`**
> （页面源码里行分隔符是 `|\n`）。我第一次多写了一个 `|` → `setDocumentSource` 返回 **`False`** 且**页面无变化**（无损失败）。
> 另外 `sch_PrimitiveText` **可以 `modify(id, {content})`**，不必删除重建；按坐标匹配文本（`getState_Value()` 读不到）。

#### B7（P0 电气缺陷）`R12` 形同虚设

| 项 | 内容 |
|---|---|
| **现象** | `LCD_BL_CTL = {EVK1.11, J5.28, R12.1, R12.2}` |
| **根因** | R12 两端**都挂了同名 `LCD_BL_CTL` 旗标** ⇒ EDA 按**网名**并网 ⇒ 1k 串阻被自己两端的标签短路 |
| **为何 DRC 不报** | 电气上不算"错误"（只是电阻没起作用）；且两脚分属两个**独立几何连通域**，常规"同网检测"抓不到 |
| **定位依据** | `EVK1.11` 引脚在 `(370,555)`、其旗标在 `(340,555)`；`R12.1/2` 在 `(280/320,555)`；`J5.28` 的旗标在 `(750,1100)` |
| **修法** | 把 **EVK1 侧**那颗旗标 `@(340,555)` 改名 **`LCD_BL_PB0`**（删除 + 原位 `createNetPort("BI", …)` 重建，沿用 rot=180） |
| **结果** | `LCD_BL_PB0 = {EVK1.11, R12.2}`　`LCD_BL_CTL = {R12.1, J5.28}` ✅ 串阻真正串在 `PB0 → J5.28` 通路里 |

#### B8（命名卫生）基准网名不再写死电压

依据 **D5**（"3.0V→1.5V / 3.3V→1.65V 两种都对"）+ **S-c**（"写成 VREF/2，去掉 3.3V 固定硬编码"）：

| 旧名 | 新名 | 旗标数 | 理由 |
|---|---|---|---|
| `VREF_3V3` | **`VREF_ADC`** | 4（AFE） | 核心板 REF3030 = **3.0V**，旧名可能本来就是假的 |
| `VREF_3V3_EXT` | **`VREF_CORE`** | 2（INT 1 + AFE 1） | 它是"从核心板取来的基准"，不是固定 3.3V |
| `VBIAS_1V65` | **`VBIAS`** | 7（INT 1 + AFE 6） | = `VREF/2`，3.0V 档下是 1.50V |

> **踩坑**：改端口名后 DRC 冒 2 条新警告 *"网络端口 X 的名称与所连导线名称 Y 不一致"* ——
> **导线自身也带 `net` 属性**（`getState_Net`），改端口名**不会**同步它。
> 用 **`sch_PrimitiveWire.modify(id, {net})`** 显式改（INT 页那 2 根跨页短线 `bf14435dd5614df3`/`8dd7720f713ef5f4`），DRC 即回 2 条。

### 5.6 B10：**屏幕接口 SMD → 通孔直插**（2026-09-30，用户指令"15 对 pin 的屏幕插口换成通孔的插件，不要贴片"）

| 件 | 符号脚号编排 | 封装 | 可购 |

| 原 `J5` `2.54-2*15P立贴母`（C5122337） | **U 形**（1~15 左列到底，16~30 右列回来） | `HDR-SMD_…` 贴片 | ✓ |

§4 的网表本来就是照"逐行"写的 ⇒ 换到 C58377 **顺便把 `§5.4-①` 那条隐患消掉**，
且改完图上**逐行显示成 `CS|RS`**，与实物丝印一致。

### 5.7 B11：**输入端子 BNC → SMA 贴片座**（2026-09-30，用户方案）

#### ⚠️ 落 PCB 时必须遵守的两条（**不是建议，是判据**）

1. **`R1`(49.9Ω) 必须紧贴 SMA 中心针（≤2~3mm）** —— 中间那段走线就是电感，越长匹配越烂。
   图上距离 180 单位是**原理图坐标**，不影响；PCB 上必须贴着排。
2. **贴片 SMA 座的机械弱点要人为补偿** —— 插拔力与线缆弯扭力全压在 SMD 焊盘上（用户已确认选贴片）：
   - 座子**尽量靠板边**，让外壳/法兰能顶到机壳或承力结构；
   - 焊盘**加宽铺铜 + 多打过孔**到地；
   - 有条件时在座子周边**灌锡/加结构胶**；
   - 拔线时**捏住座子**而不是拉线。

### 5.8 B12：**两处致命缺陷修复 + C14 去耦补齐**（2026-09-30，AFE 页）

> 触发：用户提出"继续优化电路设计（感觉还缺两个跟随器）"。**先做全页跨页命名网逐条核对**，

#### 缺陷①（致命）**U1A 缓冲输出被并入 `+5V_A` 电源网**

| 项 | 内容 |
|---|---|
| 现状（实读） | 一条合并折线把 U1A 输出节点 `{U1.1, U1.2, R3.1}` 经 `(830,1100)→(760,1100)` 连到 `(760,1100)` 的 `+5V_A` 旗标（该旗标是 `U1.8`(V+) 的供电落点）⇒ 网表 `+5V_A = {C11.1, D1.5, R3.1, U1.1, U1.2, U1.8}` |
| 来源 | B10 修复"补回 U1 供电落点"时，把 U1A 输出的绕行线画到了 `(760,1100)` 这一点上 |
| 后果 | 落 PCB 后运放输出直连 5V 轨：U1A 输出级持续对电源灌电流（短路保护态），R3→LC→后级全被钉在 +5V |
| 为何 DRC 不报 | "输出并进电源网"不是电气规则违规（两连通域挂同名旗标 = EDA 眼里的正常跨距离连接）|
| 修法 | 删该合并折线，重画 3 段：输出主线 `(800,1050)-(880,1050)` / U1.2 反馈绕行 `(720,1060)→(690,1060)→(690,1140)→(830,1140)→(830,1050)`（**绕开 (760,1100)**）/ U1.8 供电短线 `(760,1080)-(760,1100)` |
| 验证 | 网表回读 `+5V_A = {C11.1, D1.5, U1.8}`；`{R3.1, U1.1, U1.2}` 恢复独立匿名节点 |

#### 缺陷②（致命）**`R7` 落点在 AGND ⇒ U1B 直流饱和**

| 项 | 内容 |
|---|---|
| 现状（实读） | `U1B` 同相 ×4：`+in` 偏置 `VBIAS`（经 R5 10k），`−in` 侧 R6(30k) 到输出、**R7(10k) 到 AGND** |
| 直流点计算 | `Vout = VBIAS × (1 + R6/R7) = 4 × VBIAS ≈ 6.0~6.6V > 5V 轨` ⇒ **输出饱和在上轨，整机测不出任何信号** |
| 修法 | `R7.1` 的落点由 AGND 改 **VBIAS**（原位：删 `AGND@(2140,1290)` 旗标 → 重建 `VBIAS` 净标签；短线 `(2140,1290)-(2140,1270)` 未受连带删除，保留） |
| 验证 | 网表回读 `VBIAS = {C13.1, R10.1, R2.2, R5.2, R7.1, R9.2, TP5.1}`、`AGND` 不再含 `R7.1`；直流输出 = VBIAS、AC 增益 = 4（不变） |

#### 决策：**不加跟随器**（用户拍板 2026-09-30）

原话"感觉还缺两个电压跟随器 OPA2197"。逐候选量化后**不加**：

| 候选位置 | 量化收益 | 结论 |
|---|---|---|
| LC 输出"后跟随"（R4 终接节点 → 跟随 → C9） | ≈0：U1B 同相输入高阻、C9(100nF) 串入，对 49.9Ω 终接节点加载可忽略（500kHz 处 C9≈3.2Ω 串 R5 10k） | 不加（与 `02-architecture §3`"不加第三管"一致） |
| VBIAS 缓冲（R9/R10 5k 源阻抗 → 跟随 → 低阻偏置） | 小：R7 反馈电流 6.25µA 经 C13(10µF, @10kHz≈1.6Ω) 仅产生 ~10µV 误差（0.016%），可忽略 | 不加 |
