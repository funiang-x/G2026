## 5 · 本次改动（C1 / C9 → 0805）

| 项 | 改前 | 改后 |
|---|---|---|
| 位号 | C1、C9 | 不变 |
| 数值 | 100nF | 100nF |
| 封装 | **C1206** | **C0805** |
| MPN | 1206CG104J500NT | **CC0805KRX7R9BB104** |
| LCSC | C46348 | **C49678** |

**做法与理由**：
1. 直接改封装引用会走平台的 `rebind-footprint` 事务，本次实测该事务在这颗器件上失败
   （返回 `EDA_CALL_FAILED`、回滚未验证）。因此改用 `sch replace` 换成工程内已验证的 0805 器件
   （与 C14/C22 同料号）。
2. 换件后符号引脚间距由 30 单位变为 40 单位，原导线端点需要重画。**两处网络的导线已按原拓扑重建**，
   改动后回读：
   - `C1`：pin1 与 `R1`/`D1` 同网，pin2 与右侧网络同网；
   - `C9`：pin1 与左侧网络同网，pin2 与 `2240` 竖支同网；
   - 全工程 `sch nets` = 68 网（与改前同数），0 单引脚网；`bridge-check` 0 短路 0 孤桩。
3. 换件会清空部分自定义属性：已回填 `C1` 的 LCSC（C49678）与 `C9` 的 Value（100nF），
   回读确认两者现在同属 BOM 行 `C1 C9 C14 C22 / 100nF / C0805 / C49678`。

**副作用（需要知道）**：
- 介质由 **C0G（1206CG…）** 变为 **X7R（CC0805KRX7R…）**。C1 是耦合电容，无影响；
  C9 在滤波并联臂上，X7R 的容值随温度/直流偏压有小幅变化（3.3V 偏压下远小于容差），
  若后续要压滤波精度，可换 0805 C0G（100nF/50V 的 0805 C0G 较少见，需另选型）。
- C1 与 C9 的**符号引脚间距**仍不同（C1 为 40 单位、C9 为 30 单位），电气等价，仅外观不同。
