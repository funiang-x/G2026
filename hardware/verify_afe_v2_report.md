## 4. 文档数字对照（发现的问题）

- 软件文档 §6 写「@1.5MHz −43.7dB → 残留 0.655mV」。精确值 −43.7 dB ✓（衰减本身对）。
- 但按其 §3 链路（端接×0.5 → ×4 → 滤波）推残留 = 100mVpk×0.5×4×0.006546 = **1.309 mV pk**，
  与 0.655mV 差 **2 倍**——文档该行少算了端接分压与增益的其中一项（LTI 链上增益与滤波可交换，顺序不影响结果）。
- 修正后预算：混叠残留 1.31 mV（原 0.655）→ RSS ≈ 1.31 mV，对 5mV 判据余量 ≈ 3.8×（原称 7.5×）。仍达标，但 §6/§10 两行数字须回改；
  **改动任何参数 → 按文档 §14 要求重跑 tools/verify_dsp.py 后回填**（本报告只裁定解析界，统计最坏以重跑为准）。

## 6. OPA2197 压摆率/摆幅/噪声核算

- 滤波在前：运放只见 ≤62 mVpk 带内信号（u_J 残留 0.33 mVpk@输入），输出 ≤250 mVpk @≤500kHz；
- 需求 SR = 2π×500k×250mV = 0.79 V/µs ≪ 20 V/µs ✓（对照：若增益在前，u_J=200mVpk@1.5M 需 1.9 V/µs，也 < 20，但 IM3 风险高——仍选滤波在前）
- 输出摆幅：1.65V ± 250 mV = 1.40~1.90 V，RRIO 5V 供电 ✓（对 1.65V 半量程余量 1.40 V）
- 噪声：运放 ~2.9nV/√Hz×4×√(500k×π/2) ≈ 10.3 µV rms；50Ω 源热噪 ~0.4 µV rms —— 距 5mV 判据均 >50× ✓
- 半程 B 半管 = 1.65V 基准缓冲（VREF3033÷2 分压），兼作上电自检已知电平（软件文档 §9 自检要求）✓
