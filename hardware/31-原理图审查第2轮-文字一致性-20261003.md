## §1 审查方法（可复用）

```
① sch text-list ×3 页        → 拿到全部文字（content / x / y / fontSize / primitiveId）
② sch list --include-pins    → 拿到全部位号与**现值**
③ 交叉核对两件事：
   a) 文字里提到的**位号**，图上还存在吗？（查"删件后残留"）
   b) 文字里写的**数值**，与网表现值一致吗？（查"改值后过期"）
④ 再人工过一遍**事实性措辞**（不是数值，是"说法对不对"）
```

**③ 的判据写成了脚本**（`_archive/_review4/eda/` 下），核心是把"位号 + 紧随其后的数值"配对，与网表 `otherProperty.Value` 归一化比较。
**注意假阳性**：`100n` vs `100nF`、`470p` vs `470pF` 是**同一值不同写法**，不是过期；
`J5 30-pin` 里的 "30" 是**脚数**不是值。

## §3 处理方式

### 3.1 为什么不能"改"，只能"删 + 重建"

| 试过的路 | 结果 |
|---|---|
| `sch modify --id <textId> --patch {"content":"…"}` | ❌ `Unknown component patch field(s): content`（合法字段只有 x/y/rotation/…/otherProperty） |
| `sch modify --id <textId> --patch {"name":"…"}` | ❌ `Failed to read component` —— **文字图元不是"元件"**，modify 够不着 |
| `sch rename` | ❌ 只能改**整张原理图文档**的名字，不是文字 |
| **`sch frame apply`** | ✅ **能新增任意文字**（frame 的 `title`），且**幂等** |

### 3.2 执行

```
① prim-delete 删掉 11 条过期/错误文字（AFE 6 · INT 3 · PWR 2）
② frame apply 补回更正后的说明：
   · AFE：3 条更正标签（U1B 增益 / R8+C10 / R1 端接 / R3 双角色）
   · INT：2 个分区标题**扩写**（把被删的注释并进标题）+ 1 条跨页网更正
   · PWR：1 条 R21 更正标签
③ 保存 → 关页重开 → 回读 → 门禁
```

**为什么 INT 用"扩写标题"而不是新加框**：`frame apply` 有 `partition-overlap` 校验
——新框若落在既有分区框内会被**拒绝**。而原来的注释本来就画在分区框里 ⇒ 改成把内容并进分区标题，
**零新增框、零重叠**。

### 3.3 顺带修掉的既有缺陷

**INT 页 ③ 分区的框 `minY=60`，而 `R40`/`R41` 在 `y=-50`** ⇒ 框**没盖住那两只电阻**。
已把 `minY` 扩到 **-90**（`18 §3.3` 记过"第二轮新增 18 只、10-02 又补 R40/R41"，框没跟着长）。

## §5 本轮**没做**的（诚实边界）

| # | 项 | 为什么没做 |
|---|---|---|
| 1 | **把 13 条全部恢复成"原来的排版样式"** | 只能用 frame title（带虚线框）表达，样式与原文字不同；本轮把**内容正确**放在**样式一致**之前 |
