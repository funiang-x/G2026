## 2. 改了什么（AFE 页）

### 2.1 信号链：标签 → 实体导线

原状：主链 y=1050 上，元件之间靠「引脚 → 10 单位短线 → 网络标签 → 另一段短线 → 下一个引脚」
连接，一眼看不出信号怎么流。

现状：**J1 → D1/R1/C1 → JP1 → U1A → R3 → L1…L7（8 阶 LC 梯形，C2/C4/C6/C8 分支到地）
→ R4/C9 → U1B → R8/C10 → JP2 → J2** 全链**一根根实体导线**，可目视追。

### 2.2 ★ 运放反馈网络（用户点名要看的）

**U1A（单位增益缓冲）**：输出 `U1A.1` 经 `(800,1050)→(800,990)→(690,990)→(690,1060)→(720,1060)`
**绕回**反相输入 `U1A.2` —— 回路可见（走元件下方，避开 V- 引脚）。

**U1B（同相 ×4）**：

```
                    ┌──── R6 (30k, 反馈电阻) ────┐
                    │                            │
   U1B.2 ◄── 反馈节点 ●───────────────────────► U1B.1 (输出)
     (-in)          │   (2220,1060)~(2220,1230)   │
                    │                            │
                  R7 (10k)
                    │
                   AGND
```

- 反馈节点竖线 `(2220,1060)→(2220,1230)`；`U1B.2` 横接、`R6` 上支路横接、`R7` 下支路横接；
- `R6` 下端 `(2300,1130)` 经 `(2360,1130)→(2360,1050)` 接回输出；
- `R7` 下端接 `AGND` 旗。
- 增益 `1 + R6/R7 = 1 + 30k/10k = **4**`，与 `docs/02-architecture.md` 逐字吻合。

### 2.3 电源/地/轨：netport → netflag

`AGND`（22 处）改**接地旗**、`+5V_A`（6 处）改**电源旗**；`VBIAS_1V65` / `VREF_3V3` /
`VREF_3V3_EXT` 保留为净标签。**每个标签都补了一根到引脚的短线**（v1 漏了，v2 修）。

### 2.4 网名保住了

内部网络（`AFE_TERM` / `F1~F5` / `AFE_*`）在导线上各放**一个**净标签以保住网名，
而不是每个引脚一个。

## 3. 过程中发现的两个**原图问题**（已报告，未擅自定夺）

### 3.1 ⚠️ J2.7 同时有 NC 标记**和**一条接到它的导线（自相矛盾）

- `07-无连接标志待点清单.md` 把 J2 的 **7~14 脚**登记为 NC；但原图又有一条导线
  `(2640,1050)→(2670,1050)` 接到 **J2.7**。
- 实测：**带 NC 标记的引脚拒绝建导线**（`create failed!`）→ 那条线其实是**死的**。
- 本轮处置：**保留 NC**，`AFE_ADC_IN` 只走 **J2.4**（未打 NC）→ JP2.2。
  **净表结论与 `04-pinout连接表.md` 第 5 行（U2B 出 → 核心板 PA0）不冲突。**
- **待你确认**：J2.7 到底该不该是 NC？（若该用，需在 EDA 里先取消该脚 NC，我再补线。）

### 3.2 元件放置离 10 单位格点（31 条格点警告的根因）

AFE 页 81 个标签偏离格点 1~7 单位，根因是**部分元件的引脚本身就不在格点上**
（例：`C1` 引脚在 385/415）。本轮**没有挪件**（挪件会牵动其全部连线），
改法是**把标签吸附到格点并补短线** → AFE 页格点警告已清零。
**要彻底治本需挪件**，属高风险，待你拍板。
