8.4.. Serial Peripheral Interface (SPI) 
8.4.1 3-Line Interface 
The Serial Peripheral Interface (SPI) is selected by setting the IM[2:0] pins as “101” level. The chip select 
pin (CSX), the serial transfer clock pin (SCL), the serial data input pin (SDI) and the serial data output pin 
(SDO) are used in SPI mode. The ID pin sets the least significant bit of the identification code. The DB[17:0] 
pins, which are not used, must be tied to GND

8.4.1.1 Write Sequence. 
In the write mode of 3-line serial interface contains a D/CX (data/command) select bit and a 
transmission byte. If the D/C bit is “0”, the transmission byte is interpreted as a command byte. If the D/C bit is 
“1”, the transmission byte is display data, or stored in the command register as parameter data. 
 
The instruction of ST7796s can be sent in any order, and the MSB is transmitted first. The 3-line serial 
interface is initialized when the CSX keeps high level. In this state, the SCL clock pulse and SDA data have 
no effect. A falling edge on CSX enables the serial interface and indicates the start of data transmission.
