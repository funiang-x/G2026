§3 关键位置关系速查

AFE

  • U1 摆中央 —— 两半片在链的两端，梯形要绕它一圈
  • 先 U1，再往两边排
  • 输入节点（L1 前）与输出节点（C8 处）不许绕回来耦合
  • C10 在 AGND 岛靠 PA1 的角
  • −in 节点：短、不并行、不铺铜

转接

  • 33Ω 贴 MCU 脚 3~5mm（最重要的一条）
  • J5 靠近 FSMC 引脚侧；J5.29 短/宽/多过孔 ≥6
  • C22 先、C21 后，都贴 J5.30
  • 总线束 ≤40mm（硬上限 60mm）、不跨分割、不穿 AFE 区

§4 12 条硬约束（37 §0）

#一句话做不到的后果
1底板 AGND 与 GND 两张铜皮不得相连（不许重叠 / 0Ω / 跳线 / 过孔桥接）第二个接地点 ⇒ 地环路，噪声底变差且不报错
2AFE 区 18 个模拟地成员只汇 EVK1.37 一个点同上
3AFE 区与数字/总线区隔 ≥10mm；数字回流不得跨过 AGND 岛mV 级模拟被数字回流借道
4R1 紧贴 SMA 中心针 ≤2~3mm中间那段走线就是电感，50Ω 匹配变烂
5SMA 座靠板边 + 焊盘加宽 + 多打过孔插拔力矩全压在 SMD 焊盘上 ⇒ 焊盘剥离
6四个电感正交摆放、间距 ≥2mm、下方不走高速线L3/L5 同为 22µH，互感最大 ⇒ 频响变
7R22~R42 贴 MCU 引脚 3~5mm 以内阻尼跑到负载端 ⇒ 只拿到 1/3~1/2 的降幅
8FSMC 总线走成一束、≤40mm（硬上限 60mm）、不跨分割2 层下"回流连续"是唯一可靠的"地"
9J5 的 GND(29) 短、宽、多过孔、周围铺铜（目标 L_gnd ≤30nH）21 条线只有 1 根地针 ⇒ 地弹，最弱一环
10C21/C22 紧贴 J5.30（≤5mm），先 100nF 后 10µF屏的电流尖峰跑回核心板取 ⇒ 闪屏
11背光回路与总线不平行（≥10mm）；背光 3V3 与其回流都走宽线60mA 是大环路干扰源；走线电阻直接吃掉 LED 余量
12层数升级判据：地平面被切成 ≥2 块 / 必须跨分割或穿越 AFE 区 / 总线 >60mm ⇒ 改 4 层差价几十元，远低于一次返工

§5 投板前自检（只查布局，电气项见 23 §1）

地与分区

  • 底板 AGND / GND 零连接件（网表核对）+ 目视两块铜皮不重叠
  • AGND 的 18 个成员只汇 EVK1.37，无第二条出路
  • AFE 区与数字区隔 ≥10mm；总线未跨越 AGND 岛
  • AGND 岛与 GND 铺铜之间无过孔 / 跳线桥接

块① ADC 采样

  • R1 距 SMA 中心针 ≤2~3mm
  • J1 靠板边、焊盘加宽、多打过孔
  • D1 在 R1 之后、C1 之前
  • C11/C14 紧贴 U1.8，地回路同一点
  • C13 的地是 AGND（不是 GND）
  • VBIAS 走线短、不与数字线平行
  • R6/R7 紧贴 U1B 的 −in（≤3mm）；−in 节点短、不并行、不铺大铜
  • R6=24.9kΩ / R7=3.57kΩ（不是 69.8k/10k）
  • C10 在 AGND 岛最靠 PA1 的一角；AFE_ADC_IN 独占、两侧 guard
  • TP1~TP5 探针可达

块② 滤波

  • 四个电感正交、间距 ≥2mm、下方不走高速线
  • C2/C4/C6/C8 地过孔紧贴焊盘、朝同一条铜皮收拢
  • C8 与 R4/C23 的地汇在同一处
  • C23 在 R4 与 AGND 之间（不是并在 C8 上）
  • R3 紧邻 U1A 输出
  • TP3 探针可达

块③ 转接

  • R22~R42 全部贴 MCU 引脚 3~5mm 以内（逐个目视 + 尺量）
  • 总线走成一束、≤40mm、束内每 2~3 根插地
  • J5 靠近 FSMC 引脚侧
  • J5.29 短 / 宽 / 多过孔 ≥6，周围铺铜
  • C21/C22 紧贴 J5.30（≤5mm），先 100nF 后 10µF
  • R15/R16 靠 J5 侧 ≤10mm；TP_SCL/SDA 不与总线平行
  • 背光回路与总线 ≥10mm；背光 3V3 与回流都 ≥0.5mm

电源与结构

  • C16 紧贴 +5V
  • R21 在数字 / 模拟分界；+5V_A 不绕进数字区
  • 屏模组刚性固定，无杜邦飞线
  • 重新核对层数升级判据

§6 诚实边界

  1. 板框 / 安装孔未定（29 G3）⇒ 位置是相对关系，不是量图。
  2. §4-7/§4-8 的量化来自仿真（36 §F），不是实测。排序（源端优于负载端）稳健，绝对值不稳健 —— 上板要用示波器看 J5 侧过冲复核。
  3. §4-9 的"过孔并联降到 1/N"是量级结论；L_gnd ≤30nH 上板前没有实测手段，只能间接判。
  4. 背光那条依赖还没测的数（模组 Vf 未知）—— 测出电流之前不该动手改。
  5. 本文不含：丝印规范、拼板与工艺边、阻抗控制（本板无 50Ω 受控阻抗要求 —— 唯一的 50Ω 段靠 R1 的物理位置解决）。
