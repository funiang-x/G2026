## 2. 椭圆（Cauer）滤波 PlanB 量化：残留 = 1.309mV × 10^((−43.7 + Amin_dB)/20)

- Amin=50dB（零点@1.5M）→ 最坏残留 0.634 mV，RSS ≈ 0.64 mV，余量 7.8×
- Amin=60dB（零点@1.5M）→ 最坏残留 0.200 mV，RSS ≈ 0.23 mV，余量 21.9×

n=6 椭圆（3L/3~4C）比巴特沃斯 n=8（4L/4C）**还少一个电感**，但元件值非 E24、零点随容差漂移、
DSP 文档滤波器模型要改 → **现在不做，作为实测残留超标的 Plan B 挂起**。

## 3. 增益 ×4→×6 的真实收益

- LSB(输入折算): 0.201→0.134 mV；量化项(√N 增益后): 0.0013→0.0009 mV；**收益 0.0004 mV → 拒绝**

## 4. 双帧变频识别 u_J（fs1=2.0282M/K71 + fs2=1.9726M/K73，各一帧）

- 机制：同一 f_J 在两帧折叠到不同频率，真分量频率不动 → 谱线对帧配对，移动者判为 u_J 剔除，
  残留项 → ~0.1mV 量级，RSS → ~0.15mV，余量 → ~30×。
- 代价：软件文档 §5/§6 重写 + verify_dsp 全重跑 + 双帧时序；当前余量 3.8× 已够 → **挂「精度拉满」可选项，不做**。

## 5. 端接 ×0.5 的价值固化

- 不端接（BUF1 直读，链路 ×4）：残留 = 100mVpk×0.006546×4 = 2.618 mV **> 1.5mV 峰门限**（伪峰风险，须抬门限）；
- 端接（现状）：1.309 mV < 门限 ✓ → 端接不是损耗，是链路里唯一免费无失真的抗混叠增益。
