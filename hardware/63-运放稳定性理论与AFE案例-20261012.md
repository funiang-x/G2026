## §1 记号：`Rf‖Rg` 是什么（先把符号说清）

- **`‖` = 并联**：`Rf‖Rg = Rf·Rg/(Rf+Rg)`，单位 Ω。**不是比值**，是"两个电阻并肩时谁小谁说了算"的等效值。
- 本板实例：`R6`=53.6 kΩ、`R7`=3.57 kΩ ⇒ `R6‖R7` = 53.6k×3.57k/(53.6k+3.57k) = **3.35 kΩ**。
  （`hardware/37 §3.4` 里写的 **3.12 kΩ** 是 `R6`=24.9 kΩ 时代的同一个量，同 §3 的演进。）
- **它为什么会出现在极点公式里**：−in 节点上挂着三条通路（对地电容 `C_in`、到输出的 `Rf`/`Cf`、到源或基准的 `Rg`），
  把反馈系数展开后，"电容看到多少电阻"这一项正好是 `Rf` 与 `Rg` 的并联：

  ```
  1/β = (1 + Rf/Rg) · [1 + s·(Rf‖Rg)·C_in] / (1 + s·Rf·Cf)        ……(1)
  ```

  ⇒ −in 上的极点 `f_p = 1/(2π·(Rf‖Rg)·C_in)`。
- **两个好记的等价写法**：
  - `Rf‖Rg = Rf / NG`，其中 `NG = 1 + Rf/Rg` = 直流噪声增益 = `1/β`。本板 `NG`=16.0 ⇒ `Rth` = 53.6k/16 = **3.35 kΩ**；
  - 因此 **`Rf‖Rg` 是"你自己选的"**（可以让它 3 kΩ，也可以让它 1 MΩ）——这正是 §2.2 那条"−in 比输出贵"的来源。

## §2 理论主干（够用版）

### 2.1 三个量：A、β、T

| 量 | 是什么 | 由谁决定 |
|---|---|---|
| `A(s)` | 运放开环增益 | **器件**（本仓用宏模型：单主极点、GBW 10 MHz、`Ro` 100 Ω） |
| `β` | 反馈系数 | **完全由外部无源网络决定**（与运放无关） |
| `T = A·β` | 环增益 | 判据：`|T|=1` 处的相位裕度 `PM = 180° + ∠T` |

- 单主极点运放 + 纯电阻 `β` ⇒ `PM = 90°`（**基准**）；**每一个"外部极点"都从这 90° 里扣**。
- 穿越频率 `f_c = GBW·β = GBW/NG`。
- ★ **一切排序都来自这一条**：外部元件能吃多少裕度 = 那个极点的位置 与 `f_c` 的比值。

### 2.2 −in 节点：把 (1) 式读成两句话

- **分子里的零点 → 环内极点 → 吃裕度**：

  ```
  θ_in = arctan( 2π · f_c · (Rf‖Rg) · C_in )                        ……(2)
  ```

- **分母里的极点 → 环内零点 → 补裕度**：抵消条件 `Rf·Cf = Rg·C_in`（即 `Cf = C_in·Rg/Rf`）。
- 物理读法：`C_in` 与"`Rf‖Rg` 这团电阻"构成 RC 滞后；`Cf` 给出一条高频旁路，让噪声增益在关键频段不再上升。
- **为什么 −in 比别处贵**：`Rf‖Rg` 由你选（kΩ~MΩ），而输出节点看到的只是运放自身的 `Ro`（几十~百 Ω）。
  本板 **3.35 kΩ / 100 Ω = 33×** —— 这就是"同样的 1 pF 放错地方代价差 33 倍"的出处。

### 2.3 输出节点

- 代价 `θ_out = arctan(2π·f_c·Ro·C_load)` ……(3)
- 但它**不是必须接受的**：只要**反馈点取在输出脚、在反馈点之后串 `R_iso`**，`C_load` 就整条移出环外，(3) 式不再适用。
- 一般化：**`θ = arctan(2π·f_c·R_seen·C)`**，`R_seen` = 该节点看到的电阻。
  ⇒ **排序原理：比"谁贵"要比 `R_seen × C`，不是比 `C`**。这既是"−in 第一、输出第二"的真正来源，
  也立刻给出它的反例（§2.5）。

### 2.4 三条能动手的杠杆（从 (2) 式直接读）

| 杠杆 | 动作 | 代价 |
|---|---|---|
| 降 `Rf‖Rg` | 反馈电阻整体取小 | 功耗↑、对前级负载↑ |
| **抬 `NG`** | 把增益做大（本板 B1 就是这条路） | `f_c` 下降 ⇒ 带宽↓ |
| 加 `Cf` | 在 `Rf` 两端并一颗 C0G | 闭环多一个极点、容差不确定 |

> 记账式子：`θ_in = arctan(2π·GBW·Rf·C_in/NG²)` ⇒ **增益翻倍 = 代价砍到约 1/4~1/2**（本板实测 16.4°→8.8°）。

### 2.5 例外清单（军规什么时候不成立）

1. **β=1（跟随器）**：`f_c` 顶到 GBW（最高），且 −in 就是输出脚（`R_seen` 从 kΩ 掉到 Ω）⇒ **名次可能对调**。本板 `U1A` 正在这一档（§4.1）。
2. **`Rf`/`Rg` 很小**（50 Ω 系统）⇒ −in 的 `R_seen` 优势消失。
3. **CFB（电流反馈型）运放**：−in 是内部缓冲的输出，对电容天生敏感，datasheet 通常直接写"不要在此脚加电容" ⇒ 从"尽量"升格为"铁律"。
4. **电源/地不是"寄生"那一类**：去耦失效、共地阻抗耦合造成的自激与 (2)(3) 无关，属另一章（§5.3）。

### 2.6 判据化（可直接勾）

- 预算：外部极点**总代价 ≤ 10–15°**（给器件自身留 ≥45–60°）。
- 电容上限：`C ≤ tan(θ_max)/(2π·f_c·R_seen)`。
- 走线长度上限：`L ≤ C_max / c′`（`c′` = 走线电容密度，取值讨论见 §5.2 / §5.4）。
- 若 `C` 必须大 ⇒ 加 `Cf`（`RfCf=RgCin`），或降 `Rth`，或抬 `NG`。

## §3 六条军规的判定（结论表）

| 军规 | 判定 | 理论修正 |
|---|---|---|
| 1. −in 对地寄生是自激**第一**主因 | **成立（有条件）** | 严格式 = (2)；"第一"来自 `Rf‖Rg ≫ Ro`，不是绝对名次 |
| 2. 输出对地寄生**第二** | **成立但可豁免** | 可用 `R_iso` 移出环外 ⇒ (3) 不适用；β=1 时可能升到第一 |
| 3. 单电源 −in 与 Vref 间不接电容 | **成立** | `Vref` 交流上即地 ⇒ 与"−in 对地电容"等价；**但 Vref 自己的去耦电容必须留** |
| 4. −in 区域底面挖空 | **方向对、收益要算** | 收益 = 挖掉的那部分 C（(2) 式换算）；双面板介质厚 ⇒ 收益通常零点几度（§5.4） |
| 5. −in 走线不与输出平行 | **做法对、理由反了** | 该杂散**等价于给 `Rf` 并 `Cf`**（方向上是补裕度）；真危害 = 量值不可控 + 强信号注入高阻节点。零容忍版：**输出别靠近 +in**（正反馈） |
| 6. `Rf`/`Cf` 紧贴 −in、环路最小 | **成立** | 节点铜面积就是 C 的载体（(2) 式）；环路面积影响拾取与辐射 |

> **2026-10-12 修订（用户扩写版军规）**：第 5 条被扩成"**−in 和 +in** 都不与输出平行/靠近"——
> 这两半的机制**不同**：−in 那半是"防改补偿/防注入"（耦合等价于并 `Cf`，方向上补裕度）；
> **+in 那半才是真正"防自激"**（**正反馈：净反馈 = β − k**，`k ≥ β` 即锁定；高增益档 β 小 ⇒ 极少量耦合就要命）。
> 修订版的**逐条判定**与**六阶段设计流程/检查单**见 `hardware/64-运放设计流程与检查单-20261012.md`。

## §4 案例 A：原理图（活体网表）

### 4.1 同一颗双运放，两个半片的风险点不同

| | **`U1A`**（一级缓冲） | **`U1B`**（增益级 ×16.0） |
|---|---|---|
| 接法 | 跟随器（−in 直连输出脚） | `R6`=53.6k 反馈、`R7`=3.57k 到 `VBIAS` |
| β / NG | 1 / 1 | 1/16.0 / 16.0 |
| **`f_c = GBW/NG`** | **10 MHz**（顶到 GBW） | **624 kHz** |
| **`R_seen`（−in）** | ≈ `Ro` = 100 Ω（−in 就是输出脚） | **`R6‖R7` = 3.35 kΩ** |
| 环内外部极点 | **无**（反馈点=输出脚；梯形电容经 `R3` 在环外） | **一个**：−in 的 `C_in` |
| 该节点电容 | 12 pF（运放自身输入电容两端都落在这个节点上） | 12 pF（器件）+ 板（§5.2） |
| **代价** | **4.3°**（12 pF）· **28.8°**（100 pF） | **8.8°**（12 pF）· **10.9°**（15 pF）· **13.6°**（19 pF） |
| 若把负载电容**直挂** | `C2`=6.2 nF 直挂 ⇒ **PM 9.2°（必振）**；470 pF 直挂 ⇒ PM 32.3° | `C10`=470 pF 直挂 ⇒ PM 71.1°（**同一颗电容，在 β=1 档只剩 32.3°** ⇒ §2.5 例外 1） |

> 数字口径：宏模型复算（`_work/opamp_stability_20261012/loop_pm.py`），基准 90°。
> **`R3`(49.9 Ω) 与 `R8`(100 Ω) 的作用就在这张表的最后一行** —— 它们不是"随便一个串阻"。

### 4.2 三条"结构保护"（都在你板上，属于"设计手法"而非"躲避"）

1. `U1A`：反馈点取在输出脚，`R3` 串在**反馈点之后** ⇒ 8 阶梯形的 6.2 nF **不在环内**；
2. `U1B`：同法，`R8` + `C10` 在环外 ⇒ ADC 电荷库不在环内；
3. `R6`/`R7` 由 69.8k/10k → 24.9k/3.57k → 53.6k/3.57k ⇒ −in 的代价从 **39.6° → 16.4° → 8.8°**。

### 4.3 一处理论上的隐患（既有记录，非本轮新发现）

`VBIAS` 同时是 `U1A` 的 +in 偏置、`U1B` 的 +in 偏置、以及 `U1B` 反馈网络的回地点 ⇒
`FB → R7 → VBIAS → R5 → GAININ` 构成**第二条反馈路径**（见 `tools/sim/stability_check.py` 头注）。
理论含义：**"交流地"不是"有电容"就算数，要看它在关心频段的阻抗**。本板 `C13`=10 µF 把 `VBIAS` 压得很低 ⇒ 信号频段无害；
但这条结构在高频段是否仍然低阻，取决于 `C13` 的 ESL 与布局（未测）。

### 4.4 反馈网络上**没有 `Cf`**（现状记录）

网表里 `U1B` 只有 `R6`/`R7`，没有并电容。按 (1) 式反推：要让 12 pF 的代价归零需 `Cf = Cin·R7/R6` = **0.80 pF**。
**本文不建议现在加**：8.8°（现实约 11°）仍在预算内，而 0.8 pF 自身容差与 3.72 MHz 处的新极点都是新账。
记为"上板实测有振铃时再补"。

| 12 pF（只算器件） | 8.8° | 81.2° |

### 5.3 不属本理论、但同属"自激"的两条（分开记账）

- **去耦距离**：`C14`→`U1.8` 2.23 mm（优）· `C11`→`U1.8` **3.55 mm**（DFM `decap-too-far`）⇒ 电源路径 HF 阻抗；
- **地/平面**：`AGND↔GND` 铜隙 0.127 mm、隔离带 5.97 mm < 10 mm、`SCREW3` 在 AFE 岛中央（Ø3.2 在模拟地平面上开洞）、
  `+3V3` 在 L2 切出 22.13 mm 的槽（2 条模拟线跨越）—— 这几条影响整机噪底，`hardware/59` 已按 P1/P3 记账。

### 5.4 一条**修正**：双面板上"底面挖空"的收益比想象的小

- 本板 **2 层 / 1.6 mm**：−in 节点与 L2 的 AGND 之间隔 ~1.5 mm 介质 ⇒ 微带分量只有 **~0.05 pF/mm**；
  真正的贡献来自**同层铺铜的边沿耦合**（**实测**铜到铜 0.32–0.40 mm，见 §5.1）。
- **实测确认"底面根本没挖"**：节点 6 段中点 **6/6 落在 L2 的 AGND 填充内部**。
  也就是说军规 4 在本板是**没做**（不是"做了没效果"）；要拿那 0.1–0.5° 的微带分量，
  得先在 L2 上开个洞 —— 双面板上代价大、收益小（§6 排序里排第 3）。
- ⇒ 军规 4（底面挖空）在**四层板（介质 0.2 mm）**上是主力；在**这块双面板**上，
  等价的、更有效的动作是 **① 把同层铺铜从节点旁退开（把局部 clearance 放大）**、**② 把节点走线缩短**。
- 结论不变：**"短"永远是第一位**；"挖空"只是第二档手法，且要按层数决定优先级。

## §6 建议（只提不改，按性价比排序）

| 序 | 建议 | 预期收益 | 代价/风险 |
|---|---|---|---|
| 1 | `−in` 节点铜长 **7.05 → ≤3 mm**（`R7` 收到 3 mm 内、6 段并成 2–3 段） | **1–4°** | 重布该节点几段线 + 复跑 DRC |

## §7 诚实边界

1. 所有相位数字基于**单主极点宏模型**（无真实器件的高频极点）⇒ **只能横向比较**；真实 PM 是 datasheet 性质，本仓无 OPA2197 datasheet。
2. `Cin 8p+4p` 是**假设**；板侧 1–2 pF 是**按实测间隙推的区间**（间隙本轮已实测：中心线 0.448 / 中位 0.529 mm；但"0.15–0.3 pF/mm"仍是经验值，未做场求解/实测）。
3. §4.1 最后一行（直挂大电容）是**用宏模型的量级演示**（真实器件还受 `Ro`、`L1` 限制），用于说明 `R3`/`R8` 的作用，不是仿真结论。
4. 本轮**没有改任何图/板/文档参数**；§6 的 5 条**全部未执行**。
5. 与 `hardware/37 §3.4` 的口径差异：那份把 `f_c = GBW·β` 当固定值估相位损失；本文把 `β` 的滚降也算进去（穿越点略下移），
   故同条件本文的数**乐观 0.5°（24.9k 档）~5°（69.8k 档）**。§5.2 的表用的是本文口径，两者不要混用。
6. 所有"上板/实测"结论按三态口径一律 **未验证**（装置尚未制造）。
