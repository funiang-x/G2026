## §1 新查实的两件事（改结论，不只是改数字）

### 1.1 [P0] `VBIAS` 的来源是悬空的

**机理链**（全部 [官方]，来源：`第02章…\立创梁山派·天空星-嘉立创EDA工程文件\*.epro` 解析出的网表 + 打印版 PDF P.6）：

| 事实 | 值 |
|---|---|
| `VREF+`（MCU pin21）同网成员 | `R1.1 / R2.1 / R4.1 / C5 / C6 / TP4` |
| `R4` | **47Ω，贴** —— `VDDA → VREF+`；`VDDA` = `+3V3` 经 `L1`（600Ω@100MHz 磁珠） |
| 板载基准 `REF3030AIDBZR` | **不贴** |
| `R1` / `R2`（各 0Ω） | **均不贴** ⇒ `EXT_CHIP_VERF+` / `EXT_PIN_VERF+`（排针 P1.2 = 本板 `EVK1.2`）与 `VREF+` **不通** |
| ⇒ 排针 `REF` 针 | **悬空桩**；`VREF+ ≈ VDDA ≈ 3.3V` |

**对本板的影响**：`VREF_CORE(EVK1.2) → JP3 → VREF_ADC → R9(10k) → VBIAS`，顶到 0V ⇒ `VBIAS=0`
⇒ 缓冲器/增益级全部贴地、单电源域不工作。**这与 12 号文档当年的 P0-1（`+5V_A` 没有来源）是同一类错**：
把"库里/资料里有这颗料"当成"板上装上了"。

> 12 号 §9.2 的判断"核心板'三路存其一'必有一路导通 ⇒ 底板不需要产生基准，只需**取用**"——
> **前一半对、后一半不成立**：导通的那一路是 `VDDA→R4→VREF+`（板内），
> **排针上并没有这根电压**。所以"取用排针"取到的是空气。

**本轮修法**（最小、且两种情况下都成立）：`R9` 上端由 `VREF_CORE` 改接 **`+3V3`**。
- 若那根排针真的被驱动成 3.3V：`+3V3` 与它同源，分压比不变；
- 若悬空（官方 `.epro` 所示）：偏置轨照样有电；
- 代价：`VBIAS` 参考的是底板 3V3 轨（经排针/走线）而非核心板 `VDDA`（经磁珠+47Ω），
  两者差 ≲0.2%，而幅值口径走**乘性标定表**，标定后自动吸收。
- `VREF_ADC` / `JP3` / `C12` / `TP6` 保留为**外部基准留位**（默认全悬空、不影响功能）。

### 1.2 [P0·待实测] `J5` 第 22 脚：`D14` 还是 `T_BUSY`

| 来源 | 第 6~22 脚的读法 |
|---|---|
| 官方转接板 `TK035F5501`（PDF 脚表 + Altium `SchDoc` 符号 + 1000亮度板 `.epru` padNet） | `6..21 = D00..D15`、**`22 = T_BUSY`**、`23=T_CS`、`24=T_CLK(SCL)`、`25=T_MISO`、`26=T_MOSI(SDA)`、`27=T_IQR(INT)` |
| 本板**实物丝印**（`04 §8.1` 逐行照片复核所得） | `7=D01, 8=D00, …, 21=D15, 22=D14`；`6` 为空脚 |

两者对 **奇数脚完全一致**（`7/9/11/13/15/17/19/21 = D01/D03/…/D15`），
**偶数脚与第 6/22 脚冲突**。两种可能：

1. 实物丝印对（你的板是另一种 30pin 排法）⇒ 现状正确；
2. 官方脚表对 ⇒ 底板把 `D14` 驱进了面板的 `T_BUSY`（触摸 busy **输出**），
   同时面板的 `DB14` 无人驱动 ⇒ **少了 1 个颜色位 + 一根输出对打**。

> 注意：`T_BUSY` 是**电阻触摸芯片 XPT2046** 的 busy 信号，而本模组是**电容版**
> （`04 §8.2`：电阻/电容二选一）⇒ 若 XPT2046 未贴，风险主要是"少一位颜色"；
> 但**不能靠推测**。测法见 §5-T2（两分钟通断表）。

## §3 冗余判定：改了什么、**为什么不删什么**

| 对象 | 判定 | 依据 |
|---|---|---|
| PWR `C19`/`C20` | **删**（已删） | §2-H4 |
| AFE 8 阶 LC（4L+4C） | **保留** | [复算] 同 fc=660k 下 6 阶残留 **1.45 mVpk**（门限 1.5）——已贴脸，容差一飘即破；要压门限须把 fc 降到 ≤591k，通带 @500k 掉 **−0.55dB**。多 2 颗件买 16.8dB 阻带余量 |
| AFE `R8`=100Ω + `C10`=470pF | **保留** | [复算] ADC 充电桶补充 τ=100Ω×470pF=47ns ≪ 500ns 周期；平均输入电流造成的 0.08% 增益误差是 LTI，被标定吸收。另算环路：反相端 8pF 杂散时 **PM≈64°、尖峰 +0.5dB**，不需补偿电容 |
| `TP1~TP6` / `JP1`/`JP2` | **保留** | 6 个测试点 + 2 个断点是扫频标定与分级排障的物理基础，总价 ≈¥1；`JP1/JP2` 是"BUF 入 / ADC 前"两个最有用的解耦点 |
| `D1` = SRV05-4（4 通道只用 1 路，3 脚 NC） | **保留**（可换但不值当） | 换单路 0.5pF ESD 只省 ¥0.35 与 4 个焊盘，且要重走一遍换料事务；已备料就别动 |
| `JP3` / `C12` / `TP6` | **保留为"外部基准留位"** | 删它要连带处理 INT 页 `VREF_CORE` 的端口与 `EVK1.2` 的 NC，属于"清残骸"而非"修电气"；本轮**不为美观动网表**（要清就单独一轮，见 §8） |
| PWR `R16`（SDA 4.7k 上拉） | **保留**（**推翻我自己的初判**） | [官方] 转接板只在 **SDA** 侧有 4.7k（1000亮度板 `e23`、通用板 `R9`），**SCL 侧没有** ⇒ `R15`(SCL) 必需；`R16` 与板上 4.7k 并联成 2.35k（100kHz 合法）。删它只省 ¥0.01，却要赌"模块批次一定有 SDA 上拉"——**不值当**。量准后若确认重复，再删 |
| `R21`=0Ω（`+5V` → `+5V_A`） | **保留 0Ω** | 12 号已论证 600Ω@100MHz 磁珠在 500kHz 只有几 mΩ，无隔离作用；0Ω 保留"可断开量测"的价值。**但注意**：H1 修好后 `+5V_A` 只剩 ~2mA，若想再做一级 RC（`R21`→4.7Ω + `C11` 22µF，拐点 ~1.5kHz）现在是可行的 |
| `F1`(PPTC) / `D2`(SS34) | **保留** | 反接 + 过流；`D2` 的 0.4V 压降对核心板 LDO（4.6V 入）无影响 |
