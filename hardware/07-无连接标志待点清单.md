## 2026-09-28 傍晚 · 连接根因修正与 DRC 收口（AI 自动执行，实测）

### 真正的根因不是"缺 NC"，而是**所有连接接错了位置**

用 `sch_Primitive.getPrimitivesBBox()` 实测确认了 EasyEDA 的引脚模型：

- 引脚属性 `(x, y)` **就是电气连接点**；
- `rotation` 指向元件**体内**，`pinLength` 是朝内的绘制长度；
- 朝外方向：`0→(+1,0) · 90→(0,+1) · 180→(-1,0) · 270→(0,-1)`。

而本页画的连接是「端口放在 `(x,y)+朝外×(pinLength+10)`、导线从 `(x,y)+朝外×pinLength` 连到端口」
——**导线靠引脚的那一端落在引脚画的另一端，等于没接**。

证据（C16）：引脚属性 (470,1200) rot=270 len=19，包围盒 y = 1199.5→1219.5，
说明引脚是从 (470,1200) **朝体内**画的 ⇒ 连接点 = (470,1200)。
而导线接在 (470,1181) —— 在元件**外侧** 19 单位处。

## 2026-09-28 深夜 · NC 全部打卡完成（**改走源码注入，不再用模拟按键**）

### 换了方法：从"抢键鼠模拟按键"改成"改页面源码"

前一条记录里说"API 放不了 NC，只能走 OS 级模拟按键"——**这个结论只对了一半**：

- **对的一半**：引脚对象 API 确实写不了。`setState_NoConnected` 运行时不存在；
  `sch_PrimitivePin.modify(id, {noConnected:true})` 静默空操作（2026-09-28 二次实测确认：
  返回引脚对象、不报错、源码里 `NO_CONNECT` 计数不变）。
- **漏掉的一半**：页面源码是一条**纯文本记录流**，NC 就是其中一条普通 `ATTR` 记录 ——
  **可以直接构造并追加**，再用 `sys_FileManager.setDocumentSource()` 整体写回。
  **全程不碰用户的鼠标键盘。**

### 为什么弃用模拟按键

本批 4 个引脚（EVK1.81~84）先试按键法：**4 次只成 1 次**（只有 .82 成功）。
原因是它依赖"抢到窗口焦点 + 精确点中引脚"，而点击画布取焦点会**清掉已有选中**，
坐标稍有偏差就落空。更要紧的是它**会抢占用户的鼠标和键盘**，用户在用电脑时会被打断。

改用注入法后：**一次全成**。

### NC 记录的确切格式（已与 57 条现存记录逐条比对一致）

```
{"type":"ATTR","ticket":N,"id":"<16位小写hex>"}||{"parentId":"<引脚primitiveId>","key":"NO_CONNECT","x":<引脚x>,"y":<-引脚y>,"value":"yes","zIndex":<整数>}
```

- `parentId` = 引脚 primitiveId（形如 `00726019c8c2f9ff-e328`）
- **`y` 取负**——源码坐标系 y 与 API 返回的 `pin.y` 符号相反（**57 条现存记录全部符合此规则**）
- `value` 恒为 `"yes"`；`ticket` 全页单调递增（写前 max=1119，故用 1120/1121/1122）
- `id` 不得与任何现有 id 撞（写前共 1118 个 id，逐一对撞检测）
- 记录流格式：记录用 `"|\n"` 连接，每条内部是 `HEADER||DATA`，**末尾无分隔符**；只做**追加**

### 关键判定：为什么 (2300,1110) 该是 `AFE_ADC_OUT`

查器件型号（**LCSC 型号自带阻值**）：

| 位号 | partId | 值 |
|---|---|---|
| R6 | `0805W8F3002T5E` | **30 kΩ** |
| R7 | `0805W8F1002T5E` | **10 kΩ** |
| R8 | `0805W8F1000T5E` | 100 Ω |
| R1 / R3 / R4 | `0805W8F499JT5E` | 49.9 Ω |

R7 从 `AFE_G2_FB` 到 `AGND`，R6 从 `AFE_G2_FB` 到 (2300,1110) —— 同相放大增益
`1 + R6/R7 = 1 + 30k/10k = **4**`，与 `02-architecture.md` 的「GAIN（OPA2197 半 B，**同相×4**）」
**逐字吻合**。
⇒ **R6 是反馈电阻 Rf，其末端必须是运放输出网 `AFE_ADC_OUT`，不可能是电源 `+5V_A`。**

同时 `U1B.8 = V+`，只能接电源。两点虽在同一条竖线上（V+ 1080 / 节点 1110 / R6.2 1130），

- (2300,1110) 保留 `AFE_ADC_OUT`（删掉误放的 `+5V_A` 旗；对应导线 `net` 改为 `AFE_ADC_OUT`）；
