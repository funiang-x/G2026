# docs/archive/ — 历史快照

> **记录"当时怎么想的"**的东西放这里：被废弃的方案、被推翻的结论、当时的实测数据。
>
> ⚠️ **本目录不被骨架引用**（`AGENTS.md` 与 `docs/0x` 都不指向这里）。
> 理由：历史结论会过期，让骨架指向它会越来越长、而且引用的都是过时结论。

## 规则

- 只读，**不追溯修改** —— 历史的价值就在于它是当时的样子。
- 文件名带日期：`2026-09-21_<主题>.md`。
- 临时笔记、AI 的作业过程也放这里（或 `.workbuddy-ai/memory/`）。

## 现状

**空。** 本工程 2026-09-21 建立，还没有需要归档的东西。

## 什么该往这里放

| 该放 | 不该放 |
|---|---|
| 「为什么当初放弃了 CubeMX 沙盒搬运」的完整论证 | 现行规则（那属于 `docs/0x`） |
| 一次上板失败的完整原始日志 | 从日志里提炼出的结论（结论进 `docs/11`） |
| 被推翻的旧版规范全文 | 对现行规范的补充说明 |

判据只有一条：**这东西过期了会不会误导人？** 会 → 进这里（因为不引用）；
不会（它是现行规则）→ 进 `docs/0x`。
