# 04 — 命名规则

> 状态：**已定稿**（2026-09-21）
>
> 权威来源：参考工程 `template/` 的全部手写文件 + `docs/00` 的分层约定。

## 管什么

文件、函数、变量、宏、类型的命名。

## 一条总原则

**名字里要能看出"它在哪一层、它是干什么的"。** 前缀不是为了好看，
是为了让 `grep bsp_` / `grep op_` 能当"按层过滤"用。

## 文件命名

| 层 | 前缀 | 示例 | 说明 |
|---|---|---|---|
| `Common/` | 无（按职责命名） | `log.h` / `log.c` | 横切工具，名字即用途 |
| `Device/` | `bsp_` | `bsp_uart.h` / `bsp_uart.c` | **B**oard **S**upport **P**ackage |
| `Operation/` | `op_` | `op_filter.h` / `op_filter.c` | 业务纯逻辑 |
| `Task/` | `app_` | `app_rtos.c` / `app_link.c` | 任务与装配 |
| `Test/` | `test_` | `test_op_filter.c` | 一个被测模块一个文件 |

- 全小写，单词间用 `_`。
- **一个模块一对 `.h`/`.c`**，同名不同后缀。
- 不与 `Core/` 下的生成物同名（`main` / `gpio` / `spi` / `usart` / `usb_otg` 等已占用）。

## 函数命名

| 场景 | 形式 | 示例 |
|---|---|---|
| 模块的公开函数 | `<前缀>_<模块>_<动作>` | `bsp_uart_send()` · `op_filter_step()` |
| 初始化 | `<前缀>_<模块>_init()` | `bsp_uart_init()` |
| 取状态（无副作用） | `<前缀>_<模块>_get_<量>()` | `bsp_uart_get_rx_count()` |
| 设状态 | `<前缀>_<模块>_set_<量>()` | `bsp_uart_set_baud()` |
| 中断回调（HAL 约定） | 沿用 HAL 名，**不加前缀** | `HAL_UART_RxCpltCallback()` |
| 模块内部函数 | 同公开形式，但声明为 `static` | `static void uart_drain(void)` |

- 动作在前、宾语在后：`op_filter_step()` 而不是 `op_step_filter()`。
- **布尔返回用 `_is_` / `_has_` 起头**：`bsp_uart_is_busy()`。
- ⚠️ 公开函数**必须有原型在 `.h` 里** —— `-Wmissing-prototypes` 会拦（见 `08`）。

## 变量命名

| 种类 | 形式 | 示例 |
|---|---|---|
| 局部变量 | 小写下划线 | `rx_len` · `now_ms` |
| 模块级静态变量 | `s_` 前缀 | `s_uart_evt_q` · `s_rx_byte` |
| 全局变量 | `g_` 前缀，**尽量不用** | `g_boot_count` |
| 结构体成员 | 小写下划线，不带前缀 | `ctx->last_ms` |
| 函数参数 | 小写下划线，与成员同名时加 `_in` | `now_ms_in` |
| 常量（编译期） | 全大写宏或 `const` | `APP_TICK_PERIOD_MS` |
| 句柄指针 | 用 `_p` 后缀（可选） | `huart_p` |

> **`s_` 前缀是硬约定**：它让"这个变量的生命周期是全程"一眼可见。
> 看到 `s_` 就该想到"它可能被中断碰到" —— 这也是判断要不要 `volatile` 的起点（见 `06`）。

## 类型命名

| 种类 | 形式 | 示例 |
|---|---|---|
| 结构体 `typedef` | `<前缀>_<模块>_t` | `op_filter_t` · `bsp_uart_cfg_t` |
| 枚举类型 | `<前缀>_<模块>_t` | `bsp_uart_state_t` |
| 枚举成员 | `<前缀>_<模块>_<值>` | `BSP_UART_STATE_IDLE` |
| 函数指针 | `<前缀>_<模块>_<动作>_fn` | `bsp_delay_fn` |

- **不用 `_e` / `_s` 后缀** —— 用 `_t` 统一表示"这是个类型名"。
- `typedef` 只在**真的带来可读性**时用（`op_filter_t` 好；`typedef uint8_t op_byte_t` 没必要）。

## 宏命名

| 种类 | 形式 | 示例 |
|---|---|---|
| 应用参数 | `APP_` | `APP_TICK_PERIOD_MS` |
| 板级事实 | `BOARD_` | `BOARD_HSE_VALUE` |
| 模块内部 | `<前缀>_<模块>_` | `BSP_UART_RX_BUF_LEN` |
| 编译期开关 | `<前缀>_ENABLE_<功能>` | `APP_ENABLE_TRACE` |
| include guard | 文件名全大写 + `_H` | `BSP_UART_H` |

- **全大写 + 下划线**。
- 数值宏**带 `U` / `UL` 后缀**（`500U` · `168000000UL`）—— 避免隐式类型提升告警。
- ⚠️ 一个宏如果**没有任何代码读它**，它是"孤儿宏"：定义存在、看着像开关，
  翻成 1 却什么都不发生。要留开关就配一道 `#if` + `#error` 闸门（见 `07`）。

## 缩写表（统一口径，不要一人一个写法）

| 全称 | 用 | 不用 |
|---|---|---|
| 接收 / 发送 | `rx` / `tx` | `recv` / `send_buf` |
| 缓冲 | `buf` | `buffer` / `buff` |
| 计数 / 长度 | `cnt` / `len` | `count` / `leng` |
| 配置 | `cfg` | `config` / `conf` |
| 毫秒 / 微秒 | `ms` / `us` | `msec` / `usec` |
| 初始化 | `init` | `initialize` / `setup` |
| 句柄 | `h`（HAL 用） / `p`（指针后缀） | `handle_ptr` |
